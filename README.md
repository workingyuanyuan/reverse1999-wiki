# Reverse: 1999 Wiki

Unofficial reference for the game Reverse: 1999 (重返未來：1999 / 重返未来：1999), built for AI agents that read with a fetch tool and for people. Not affiliated with Bluepoch.

Every arcanist from the mainland China service, which runs about two versions ahead, with what each kit does by rank, Insight materials, Portrait, Euphoria and the differences between the mainland and global clients; summoning and pity rules.

Live site: https://yuanaruru.com/reverse1999-wiki/ (English), with `/zh-tw/`, `/zh-cn/`, `/ja/` and `/ko/`. Page list for agents: https://yuanaruru.com/reverse1999-wiki/llms.txt

```
pnpm install
pnpm verify
pnpm preview
```

See `AGENTS.md` for the rules of this site and the commands that write pages from the game data.
