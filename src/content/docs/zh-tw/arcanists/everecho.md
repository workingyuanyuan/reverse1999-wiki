回聲謠沒有普通咒語卡與一般的至終的儀式：她透過隊伍以交感能量卡充能的【術具】施放咒語，並以同調值取代激情。她的術具會在兩個咒語之間切換，一個是讓每名隊友獲得【往日幽影】的攻擊，另一個是需要【久違的光】的群體治療；她還會給予我方全體【餘念】，在生命降到 1 時承擔剩餘傷害。

## 咒語

| 咒語 | 效果 |
| --- | --- |
| 往日所尋求（群體攻擊、損耗） | 對所有敵人造成 200% 現實創傷；我方全體獲得 1 層【往日幽影】，持續 2 回合 |
| 明日所期盼（群體治療） | 我方全體回復相當於回聲謠攻擊 180% 的生命；為每名隊友驅散 2 種屬性削弱、狀態異常或控制效果 |

- **明日所期盼**每次施放會消耗 1 層久違的光。耗盡時，術具會切回往日所尋求。
- 【損耗】：術具施放這個咒語後，會在當回合停用。

## 交感能量卡

| 卡片 | 效果 |
| --- | --- |
| 光的生息 | 混沌交感能量 +1；回聲謠獲得 1 層久違的光。之後除非術具正選擇於回憶中重逢，否則切換為明日所期盼。 |
| 光的生息Ⅱ | 與光的生息相同，混沌交感能量改為 +2 |
| 混沌交感能量Ⅱ | 混沌交感能量 +2 |

## 至終的儀式：於回憶中重逢

對所有敵人造成 500% 現實創傷，之後對所有敵人施加【空軀幹】持續 3 回合，使我方全體獲得 5 層往日幽影持續 2 回合，並使每名術具隊友獲得【恍然如故】持續 3 回合。之後若回聲謠持有久違的光，術具會切換為明日所期盼；沒有則切換為往日所尋求。

## 狀態

| 狀態 | 效果 |
| --- | --- |
| 術具 | 以交感能量充能；在行動序列末尾循環運轉，消耗交感能量施放咒語。 |
| 往日幽影 | 創傷加成提高相當於回聲謠攻擊的 0.6%，每持有 1 層再額外獲得創傷加成 +1%。最多疊加 15 層；再次獲得時刷新持續時間。 |
| 久違的光 | 讓回聲謠的術具可以施放明日所期盼。 |
| 告慰之歌 | 持有者損失生命時，依損失生命的比例獲得同等比例的餘念最大值。 |
| 餘念 | 生命降到 1 時，由餘念承擔剩餘傷害。上限相當於回聲謠攻擊的 400%。 |
| 修復 | 累積 4 層時，能讓持有者重新啟動因損耗而停用的術具。最多疊加 4 層。 |
| 空軀幹 | 現實防禦、精神防禦與暴擊防禦 −10%。 |
| 恍然如故 | 持有者每有 1 層往日幽影，暴擊創傷 +2%。 |
