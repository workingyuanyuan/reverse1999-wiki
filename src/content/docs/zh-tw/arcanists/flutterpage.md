紙信圈兒在任意隊友行動後都會累積【風速】，每回合開始時依風速層數從三種力場中擇一生效，為每名隊友的攻擊與額外行動附加由她造成的現實創傷。她的至終的儀式會進入吟誦，將自己的咒語轉為白鳥的問候並施放，且每回合補滿靈光。

## 咒語

| 咒語 | 1 階 | 2 階 | 3 階 |
| --- | --- | --- | --- |
| 敲，敲（攻擊 2 名敵人） | 150% 現實創傷 | 225% | 375% |
| 棉風箏（單體攻擊） | 100% 現實創傷 | 150% | 250% |

敲，敲在每一階都使紙信圈兒獲得 2 層風速，持續 3 回合；棉風箏在每一階都使她獲得【連續行動Ⅰ】，持續 1 回合。

【連續行動Ⅰ】：行動點 +1。

## 至終的儀式：長不大的夢想

紙信圈兒補滿所有靈光，將自己所有的咒語轉為【白鳥的問候】並盡可能施放，接著進入【長不大的夢想】，持續 3 回合。吟誦期間她無法獲得激情。

## 狀態

| 狀態 | 效果 |
| --- | --- |
| 長不大的夢想 | 每回合開始時補滿靈光，將她的咒語轉為白鳥的問候並盡可能施放；每回合結束時再施放一次。吟誦結束時，依當下持有的風速力場獲得 1、2 或 3 點激情。 |
| 白鳥的問候 | 對所有敵人造成 40% 現實創傷，並對主目標額外造成 40%。 |
| 風速 | 最多 50 層。回合開始時決定她的力場，並移除她先前賦予自己的其他風速力場。 |
| 紙片遊行（5 層風速） | 對我方全體生效；附加的傷害視為由紙信圈兒造成。隊友攻擊時附加 15% 現實創傷，對主目標再附加 15%。隊友進行額外行動時，消耗紙信圈兒 2 點靈光再附加 15%，對主目標再附加 15%。 |
| 床單波浪（15 層風速） | 具備紙片遊行的效果，且紙信圈兒每持有 1 層風速，該次攻擊的造成傷害 +2%、本源創傷 +2%。 |
| 告別大地（25 層風速） | 具備床單波浪的效果；額外行動必定暴擊，並獲得相當於攻擊者暴擊率 ×（暴擊創傷 − 100%）的造成傷害與本源創傷加成。 |
| 力場 | 由持有者對場上指定單位施放的效果；持有者離場時結束。 |
