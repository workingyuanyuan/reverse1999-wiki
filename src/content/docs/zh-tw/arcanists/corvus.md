告死鳥在隊伍下方維持一個術陣：湧動電場，並親自佈設它的第一級。她每次行動都獲得電能，她的追擊暴力縫合會把這些電能注入電場，使電場升到 Lv.2 與 Lv.3，每升一級對每名隊友的增益就更強。她的咒語讓她獲得多層【電弧光】以提高攻擊，並給一名敵人施加【斷裂點】，暴力縫合會消耗斷裂點觸發加成效果。

## 咒語

| 咒語 | 1 階 | 2 階 | 3 階 |
| --- | --- | --- | --- |
| 電弧絞線（單體攻擊） | 200% 精神創傷；2 層電弧光 | 300%；4 層 | 500%；8 層 |
| 玫瑰色裂紋（自我吟誦） | 目標已有高溫焊合時，2 層電弧光 | 4 層 | 8 層 |

- **電弧絞線**在每一階都給命中的目標 1 層斷裂點。
- **玫瑰色裂紋**讓告死鳥進入【縫合】2 回合，並給敵方目標施加【高溫焊合】。目標已經有高溫焊合時，告死鳥另外獲得表中的電弧光，目標獲得 1 層斷裂點。

## 至終的儀式：將飛逝縫入永恆

對一名敵人造成 700% 精神創傷，給予它 1 層斷裂點，並觸發一次暴力縫合。至終的儀式不計入隊伍的咒語獲取數量上限。

## 暴力縫合

單體攻擊，視為額外行動。造成 400% 精神創傷，以 100% 的比例受儀式威力影響，並向湧動電場注入至多 20 層電能。其餘效果取決於電場的等級；標示斷裂點的加成需要目標持有 1 層斷裂點，並會消耗它。

| 電場等級 | 額外傷害 | 消耗斷裂點時 |
| --- | --- | --- |
| Lv.1 | 無 | 告死鳥獲得 3 層電弧光 |
| Lv.2 | +200% 精神創傷 | 她每有一層電弧光，+5% 精神創傷 |
| Lv.3 | +600% 精神創傷 | 她每有一層電弧光或顫動電弧，+5% 精神創傷，儀式威力比例 +0.3% |

## 狀態

| 狀態 | 效果 |
| --- | --- |
| 湧動電場 | 術陣。回合開始時依注入的電能升級：50 以上升到 Lv.2，120 以上升到 Lv.3。電場結束時，其中的電能消失。 |
| 湧動電場 Lv.1 | 我方全體創傷加成 +15%，持續 3 回合。 |
| 湧動電場 Lv.2 | 我方全體術法威力 +25%、創傷加成 +15%，持續 3 回合。 |
| 湧動電場 Lv.3 | 我方全體儀式威力 +35%、術法威力 +25%、創傷加成 +15%，持續 2 回合。 |
| 電能 | 最多 30 層；無法被驅散。 |
| 電弧光 | 每層攻擊 +0.3%，最多 60 層。 |
| 顫動電弧 | 每層攻擊 +0.3%，最多 240 層；無法被驅散。 |
| 斷裂點 | 由暴力縫合消耗，觸發其加成效果。 |
| 高溫焊合 | 持有者受到攻擊時，告死鳥獲得 1 層電弧光。精神創傷的攻擊還會讓它的精神防禦降低 1%，累計最多 −50%，並讓她再獲得 1 層。暴力縫合優先攻擊持有高溫焊合的敵人；同一時間只有一名敵人持有。 |
| 縫合 | 每回合結束時，告死鳥以當下電場等級的效果施放暴力縫合。再次獲得時延長持續時間。 |
| 電湧增幅 | 電場達到 Lv.3 時激情 +3；電場處於 Lv.3 期間，激情上限 +5，並免疫控制效果。 |
