## 回合

每回合隊伍會拿到一手咒語牌與一定數量的行動次數（行動點），用來施放這些咒語；敵人則依自己的行動點行動。傷害取決於攻擊者與目標的靈感、創傷類型，以及下列屬性。

## 靈感克制

| 群組 | 克制 |
| --- | --- |
| 獸 | 木 |
| 木 | 星 |
| 星 | 岩 |
| 岩 | 獸 |
| 靈與智 | 兩者之間另有一組關係（靈智克制） |

遊戲把第一組稱為自然克制。攻擊靈感被克制的敵人時多造成 30% 傷害，兩組皆然。這項加成與創傷加成分開計算。

## 創傷類型

| 類型 | 減免它的屬性 |
| --- | --- |
| 現實創傷 | 目標的現實防禦 |
| 精神創傷 | 目標的精神防禦 |
| 本源創傷 | 無：固定傷害，無視所有防禦與傷害減免，也幾乎不受任何創傷加成影響 |

每位神秘學家造成現實創傷或精神創傷；本源創傷來自燃燒、中毒等狀態與部分技能。創傷類型也關係到控制：現實創傷攻擊會解除石化，精神創傷攻擊會解除冰凍（見[狀態效果](/zh-tw/systems/statuses/)）。

## 咒語與行動點

- 場上有 4 名角色（含支援）時，手牌最多 7 張咒語；上限取決於存活且上場的角色數。
- 施放咒語或移動手牌中的咒語都會消耗一次行動。把咒語移到相同的咒語上會提升它的階次，最高 3 階；階次越高效果越強。
- 我方剩下的角色越少，每回合的行動次數越少，但越容易獲得高階咒語。同樣地，擊敗敵人會減少敵人的行動次數。
- 本回合打出的咒語，在回合結算前點擊行動區即可收回。

## 激情與至終的儀式

神秘學家透過施放與移動咒語，以及部分技能，獲得施放至終的儀式所消耗的資源激情。

- 138 名已上線神秘學家中，有 131 名施放至終的儀式需要 5 點激情。
- 亞歷克西歐斯、埃齊歐·奧迪托雷、卡珊卓、琺瑯眼、回聲謠、雙生舞伶與赫多涅改為累積另一種資源。
- 心神不寧讓神秘學家無法獲得激情；部分敵人與神秘學家會移除激情。

## 屬性

| 屬性 | 作用 |
| --- | --- |
| 生命 | 降到 0 時角色退場 |
| 攻擊 | 攻擊所造成傷害的基礎 |
| 現實防禦 | 降低受到的現實創傷 |
| 精神防禦 | 降低受到的精神創傷 |
| 暴擊技巧 | 提高暴擊率與暴擊創傷 |
| 暴擊率 | 打出暴擊的機率；也是治療暴擊的機率 |
| 抗暴率 | 降低被暴擊的機率 |
| 暴擊創傷 | 暴擊的傷害；也決定治療暴擊的治療量，收益遞減 |
| 暴擊防禦 | 降低受到的暴擊傷害 |
| 創傷加成 | 提高造成的傷害 |
| 受創減免 | 降低受到的傷害 |
| 穿透率 | 無視目標部分現實防禦與精神防禦 |
| 術法威力 | 提高咒語的傷害 |
| 儀式威力 | 提高至終的儀式的傷害 |
| 治療率 | 提高給予的治療量 |
| 受創回復 | 回合開始時，回復上一回合所受傷害的一部分 |
| 吸血率 | 把造成的部分傷害轉為攻擊者的生命 |
| 本源創傷加成 | 提高造成的本源創傷 |
