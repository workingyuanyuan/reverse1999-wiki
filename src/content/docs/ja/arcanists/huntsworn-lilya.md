狩勲の魔女リーリャは速度を積み上げて戦う。チャネルのコブラ機動で【雷鳴エンジン】に入ると、毎ターン【過給】がたまり、10スタックで2ターンの【極限速度】に変わる。どの状態もスペル威力とダイブ攻撃の追加ダメージを上げる。コブラ機動を重ねて使うと【弾薬装填】がたまり、アルティメットがそれを消費して大きな一撃を放つ。リーリャは看破の神秘学家の一人で、このグループは看破ポイントを共有し、そのポイントで看破スペルを使える段階に入る。[リーリャ](/ja/arcanists/lilya/)とは別の神秘学家である。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 極限ダイブ（単体攻撃） | リアルダメージ 200%、雷鳴エンジン中は +400% と与ダメージ +10%、極限速度中は +800% と +20% | 400%、+800% と +20%、+1600% と +40% | 600%、+1200% と +30%、+2400% と +60% |
| コブラ機動（チャネル） | 雷鳴エンジンに入る。雷鳴エンジン中は弾薬装填 1、極限速度中は 2 | 2、4 | 3、6 |

- **極限ダイブ**は1ターンに1回使える。
- **コブラ機動**は雷鳴エンジンに入る。すでに雷鳴エンジンか極限速度の状態で使うと、代わりに弾薬装填を与える。

## アルティメット：この切り札を試してみて！

敵全員にリアルダメージ 900%、メインターゲットにさらに 900%。リーリャが弾薬装填を6スタック消費すると、この攻撃はリアルダメージをさらに 1800% 与え、アルティメット威力 +100%、クリティカルダメージ +100%、貫通率 +20% を得る。極限速度中に使うと【星の看破ポイント】を4満たす。これは極限速度1回につき最大1回である。

## 状態

| 状態 | 効果 |
| --- | --- |
| 雷鳴エンジン | スペル威力 +60%。各ターン終了時に過給を3スタック得る。ターン開始時に10スタックあれば、2ターンの極限速度に変わる。 |
| 極限速度 | スペル威力 +120%。終了すると過給のスタックがすべて消える。 |
| 過給 | 1スタックごとにスペル威力 +6%、最大10スタック。解除されない。 |
| 弾薬装填 | 1スタックごとにアルティメット威力 +2.5%、最大20スタック。解除されない。 |

## 看破：撃墜

リーリャは【看破の眼】を持ってバトルに入る。スペルを使う前、看破ポイントを6以上（上限15）持つチームは【弱点看破】に入れる。持ち込めるのは最大10ポイントで、そのポイントを同じ本源の看破スペルに使う。チームは看破の眼を、残光や血の薪と同時に持てない。

- **撃墜**はリーリャの看破スペルで、敵1体にリアルダメージ 900% を、クリティカルダメージ +60% つきで与える。
- **看破能力1**：弱点看破の中では、リーリャの3回目ごとの行動が敵全員への攻撃になり、リアルダメージ 2000% を、クリティカルダメージ +80% つきで与える。
- **看破能力2**：弱点看破が終わる前に、仕上げの攻撃を1回追加で行える。敵全員にリアルダメージ 3000%、クリティカルダメージ +100%、さらにその段階でチームが行動した1回ごとにリアルダメージ 150% を加える。この攻撃の後、弱点看破が終わる。
