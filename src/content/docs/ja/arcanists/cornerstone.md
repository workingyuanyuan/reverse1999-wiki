コーナーストーンはチームが軽減したダメージを蓄え、反撃に費やす。自身が場にいる間、味方全員は実現性評価を持ち、敵の攻撃1回ごとのダメージを軽減して試行記録に保存する。ほかの味方の反撃にはその保存量に応じた追加リアルダメージが乗り、敵ターン終了時に発動する自身の検証指摘と竣工検査は、試行記録をすべて消費して追加ダメージを与える。チームの追加行動でコンセプトリファインが積み上がり、アルティメットを強めるデザインリビジョンに変わる。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 築造実践（単体攻撃） | リアルダメージ 200%、検証段階中なら +200% とクリティカルダメージ +40% | 300%、+300%、+60% | 500%、+500%、+100% |
| 図と地（自己カウンター） | 【検証段階】2ターン、【コンセプトリファイン】2スタック | 2ターン、3スタック | 2ターン、5スタック |

築造実践はどのランクでも反撃とみなされる。図と地で得るコンセプトリファインのスタックは2ターン続く。

## アルティメット：ここに、明日の礎を

自己カウンター。コーナーストーンは1ターンの【竣工段階】に入り、敵ターン終了時に竣工検査で攻撃する。

## 状態

| 状態 | 効果 |
| --- | --- |
| 実現性評価 | コーナーストーンが場にいる間、味方全員が持つ。敵の攻撃によるジェネシスダメージ以外のダメージを1回につき登場時の攻撃力の最大 80% まで軽減し、軽減した量を試行記録として保存する。 |
| 試行記録 | コーナーストーンの保存枠。上限は登場時の攻撃力の 500%。ほかの味方が反撃するたび、コーナーストーンの攻撃力の 100% に等しいリアルダメージを追加し、さらに上限に対する保存割合 × 100% だけその追加ダメージを上げる。上限に達するとそれ以上は保存されないが、実現性評価による軽減は続く。 |
| 検証段階 | 敵ターン終了時、行動阻害中でもコーナーストーンが検証指摘を発動する。再び得ると持続ターンが延びる。解除されない。 |
| 検証指摘 | 敵全員にリアルダメージ 1000%。コーナーストーンはデザインリビジョンを1スタックとモキシーを1得る。試行記録を空にし、消費した 1000 ポイントごとにリアルダメージ +100%。反撃とみなされる。 |
| 竣工段階 | 実現性評価の軽減上限が1回につき登場時の攻撃力の 160% になる。敵ターン終了時、行動阻害中でも竣工検査を発動し、そのターンは検証段階が発動しない。再び得ると持続ターンが延びる。解除されない。 |
| 竣工検査 | 敵全員にリアルダメージ 2000%、モキシーを1得る。試行記録を空にし、消費した 1000 ポイントごとにリアルダメージ +100%。デザインリビジョンが5スタック以上あれば5スタック消費し、リアルダメージ +1000%、アルティメット威力 +75%、貫通率 +20% を得る。未満ならデザインリビジョンを3スタック得る。反撃とみなされ、検証段階の持続ターンを1延ばす。 |
| コンセプトリファイン | 1スタックごとに反撃ダメージボーナス +4%、スペル威力 +4%。最大20スタックで、各スタックの持続時間は個別に管理される。解除されない。 |
| デザインリビジョン | 竣工検査で消費される。最大10スタック。解除されない。 |
| 行動阻害 | 気絶、石化、悪夢、氷結、武装解除、沈黙、封印など、行動を止める効果。 |
