エル・アレフはひらめきを軸に動く神秘学家で、洞察1の伝承が毎ターン開始時にひらめきを供給する。チームが消費したひらめき1点ごとに通常スペルに配られる【啓示】が1点増え、啓示を持つスペルを使うとスペル行列の最後に【即興スペル】が追加される。アルティメットはそのターンに使われたスペルを記憶して次のターンに再発動し、さらに即興スペルで【解読】を持つ敵全員に追加ダメージを与える。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 権力と監視（単体攻撃） | メンタルダメージ 100% | 200% | 400% |
| 理想の宣言（範囲バフ） | 味方全員に【答え】 1スタック | 2スタック | 3スタック |

- **権力と監視**はどのランクでもエル・アレフに1ターンの【連続行動Ⅰ】を与える。攻撃後、ひらめきを2消費して、そのターンの即興スペルの攻撃回数を1増やす。
- **理想の宣言**のスタックは3ターン持続する。また、ひらめきを2消費して味方全員に追加で1スタック付与する。

## アルティメット：全知全能の投影

自己チャネルに入り、そのターン中に自ら最初に使用した通常スペル2枚を【記憶】し、1ターンの【超記憶症候群】を得る。

## 状態

| 状態 | 効果 |
| --- | --- |
| 連続行動Ⅰ | 行動回数 +1。 |
| 答え | スペル威力 +10%。最大4スタックで、各スタックの持続時間は個別に計算される。 |
| 啓示 | ひらめきを1消費するごとに1点増える。毎ターン開始時、通常スペルにランダムで配分される（1枚につき最大5点）。ターン終了時に未使用のスペルに残った啓示は消える。啓示を持つスペルを使うとスペル行列の最後に即興スペルが追加され、その啓示が即興スペルに蓄積される。 |
| 即興スペル | ランダムな敵1体にメンタルダメージ 200%、さらに蓄積された啓示1点ごとにメンタルダメージ 15% を追加で与える。蓄積された啓示が 3、6、12、20 点以上なら、攻撃回数がそれぞれ 1、2、3、5 回増える。ダメージは味方全員の平均ステータスで計算される。 |
| 解読 | メンタル防御力とダメージ軽減 −10%、2スタック目以降は1スタックごとにそれぞれ −2%。持続3ターン、最大8スタックで、各スタックの持続時間は個別に計算される。 |
| 記憶 | 記憶したスペルのランク、啓示の点数、変化効果を保持する。 |
| 超記憶症候群 | エル・アレフは次のターンまでチャネルを続け、その間は行動できない。チャネルは行動エリアのスペルが解決される直前に終了し、記憶したスペルがスペル行列に加わってそのターンの他のスペルに続いて発動する。これらは自ら使用したスペルとみなされるが、モキシーは得られない。その後、そのターンの即興スペルの攻撃回数が2回増え、最後の1回を除く各攻撃が対象に解読を付与し、最後の攻撃は解読を持つ敵全員にスタック数 × 80% の追加メンタルダメージを与えたあと、すべての解読を解除する。 |
