ローレンツバタフライは残光の神秘学家の一人である。敵への燃焼と光輪が残光をため、洞察3の伝承がそれを毎ターン、チーム全体のダメージボーナスとスペル威力に変え、残光の味方が多いほど大きくなる。ローレンツバタフライは【燃焼】を広げ、1つ目のスペルはそのターンにチームのスペルが対象に与えたダメージに応じてダメージを加え、アルティメットは選んだスペルの写しを作り、その写しは次のターンに行動ポイントを消費しない。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 引き金の微動（単体攻撃） | メンタルダメージ 200%、燃焼 2 | 400%、燃焼 2、固定ジェネシスダメージ 3% | 800%、燃焼 3、6% |
| 量化基準（バフ） | 自身にイグナイトウィング、2ターン | 自身とほかの残光の味方に、2ターン | 自身とほかの残光の味方に、3ターン |

- **引き金の微動**は命中の前に対象へ燃焼を付与する。ランク2以上では、そのターンに味方のスペルが対象に与えたダメージの 3%（ランク2）または 6%（ランク3）に等しい【固定ジェネシスダメージ】を加え、残光 100 ごとに 0.5%（ランク2）または 1%（ランク3）上がる（数える残光は最大 600）。この効果は1ターンに最大10回発動する。
- **量化基準**は【イグナイトウィング】を与える。持ち主の攻撃ごとに燃焼が1スタック加わる。

## アルティメット：予測不能な力学系

使用前に、ローレンツバタフライはスペル枠にある通常スペルを1枚選ぶ。【連続行動Ⅰ】を1ターン得て、選んだカードの【予備スペル】が3枚作られる。予備スペルは次のターン開始時に【フラクタル】で書き換えられて出る。

## 状態

| 状態 | 効果 |
| --- | --- |
| 燃焼 | 被回復効果 −15%（累積不可）。各ターン終了時、持ち主は自身の攻撃力の 4% に等しいジェネシスダメージを受ける。最大30回重なり、全スタックで1つの状態異常と数え、効果の発動後にスタックが半分になる。 |
| 光輪 | 被回復効果 −25%（累積不可）。各ターン終了時、持ち主は付与者の攻撃力の 4% に等しいジェネシスダメージを受ける。重なり方は燃焼と同じ。 |
| 残光 | 敵が燃焼か光輪を得るたびにたまり、場の敵が少ないほど多くたまる。血の薪や看破の眼と同時には存在できない。 |
| 固定ジェネシスダメージ | ステータスのボーナスの影響を受けないジェネシスダメージ。 |
| 連続行動Ⅰ | 行動ポイント +1。 |
| 予備スペル | 同名のスペルとして扱われる。使われなかったものはターン終了時に消える。 |
| フラクタル | カードの書き換えで、使用時に行動ポイントを消費せず、モキシーを与えず、合成できない。ほかの書き換えとは重ならない。 |
