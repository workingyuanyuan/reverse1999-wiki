コルヴスは陣法である泳動電場を味方の足元に維持し、そのLv.1を自ら展開する。行動するたびに電力を得て、追加攻撃の強制縫合でその電力を電場に注入し、電場をLv.2、Lv.3へ引き上げて段階ごとに味方全体への強化を高める。スペルでは自身の攻撃力を上げる【電弧】のスタックをためつつ、敵に【溶接】を付与し、強制縫合がこれを消費して追加効果を発動する。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 電弧スラッシュ（単体攻撃） | メンタルダメージ 200%、電弧 2スタック | 300%、4スタック | 500%、8スタック |
| バラ色のヒビ（自己チャネル） | 対象がすでに縫合対象を持つ場合、電弧 2スタック | 4スタック | 8スタック |

- **電弧スラッシュ**はどのランクでも、命中した対象に溶接を1スタック付与する。
- **バラ色のヒビ**はコルヴスを2ターンの【縫合】状態にし、対象の敵に【縫合対象】を付与する。すでに縫合対象を持つ敵に使った場合、コルヴスは表にある電弧も獲得し、対象に溶接を1スタック付与する。

## アルティメット：過ぎしものを縫い留めて

敵単体にメンタルダメージ 700%。対象に溶接を1スタック付与し、強制縫合を1回発動する。このアルティメットはチームのスペル獲得上限に数えられない。

## 強制縫合

追加行動として扱われる単体攻撃。メンタルダメージ 400% を与え、アルティメット威力を 100% の割合で参照し、最大 20 スタックの電力を泳動電場に注入する。追加効果は電場のレベルによって変わり、溶接の欄にある効果は対象の溶接を1スタック必要とし、発動時に消費する。

| 電場レベル | 追加ダメージ | 溶接あり |
| --- | --- | --- |
| Lv.1 | なし | コルヴスが電弧を3スタック獲得 |
| Lv.2 | メンタルダメージ +200% | 所持する電弧 1スタックごとにメンタルダメージ +5% |
| Lv.3 | メンタルダメージ +600% | 所持する電弧または残留電弧 1スタックごとにメンタルダメージ +5%、アルティメット威力の参照率 +0.3% |

## 状態

| 状態 | 効果 |
| --- | --- |
| 泳動電場 | 陣法。ターン開始時に注入された電力に応じてレベルが上がる（50 以上で Lv.2、120 以上で Lv.3）。電場が終わると注入されていた電力は失われる。 |
| 泳動電場Lv.1 | 味方全員のダメージボーナス +15%、3ターン。 |
| 泳動電場Lv.2 | 味方全員のスペル威力 +25%、ダメージボーナス +15%、3ターン。 |
| 泳動電場Lv.3 | 味方全員のアルティメット威力 +35%、スペル威力 +25%、ダメージボーナス +15%、2ターン。 |
| 電力 | 最大 30 スタック。解除されない。 |
| 電弧 | 1スタックごとに攻撃力 +0.3%、最大 60 スタック。 |
| 残留電弧 | 1スタックごとに攻撃力 +0.3%、最大 240 スタック。解除されない。 |
| 溶接 | 強制縫合の追加効果のために消費される。 |
| 縫合対象 | 持ち主が攻撃を受けると、コルヴスが電弧を1スタック獲得する。メンタルダメージの攻撃であればさらに対象のメンタル防御力を 1% 下げ（合計 −50% まで）、コルヴスがさらに1スタック獲得する。強制縫合は縫合対象を持つ敵を優先して攻撃する。同時に持てるのは敵1体だけ。 |
| 縫合 | 各ターン終了時、コルヴスがそのときの電場レベルの効果で強制縫合を発動する。再び得ると持続ターンが延びる。 |
| 泳動増幅 | 電場が Lv.3 に達するとモキシー +3。電場が Lv.3 の間、モキシー上限 +5、行動阻害の効果を無効化する。 |
