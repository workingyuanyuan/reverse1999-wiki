リードノットは弱い段階Ⅰから強い段階Ⅳへと巡る4段階の【栄枯】を常に循環させ、各ターン開始時と古いノートの発動で1段階ずつ進める。アルティメットは自身の段階を3ターン固定し、他の味方全員にコピーする。段階ⅡからⅣの間は致命傷を受けても倒れず、HPを回復して循環を最初からやり直す。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 新しい体験（単体攻撃） | メンタルダメージ 200%、モキシー +1 | 300%、モキシー +1 | 500%、モキシー +1 |
| 古いノート（自己バフ） | 栄枯を次の段階へ進める、デバフ1種を解除 | 次の段階へ、2種 | 次の段階へ、3種 |

古いノートはリードノット自身のステータス低下、状態異常、【行動阻害】から指定した種類数だけ解除する。

【行動阻害】：気絶、石化、悪夢、氷結、武装解除、沈黙、封印など、キャラクターの行動を制限する効果。

## アルティメット：葦の如く

リードノットが【常緑】を3ターン得て、他の味方全員に自身が持つ栄枯の段階のコピーを3ターン付与する。

## 状態

| 状態 | 効果 |
| --- | --- |
| 栄枯 | Ⅰ、Ⅱ、Ⅲ、Ⅳの順に巡る4つの段階。Ⅳの次はⅠに戻る。 |
| 栄枯Ⅰ | アルティメットを発動できない。ダメージボーナス −50%、受ける【燃焼】ダメージ +100%。 |
| 栄枯Ⅱ | 受ける燃焼ダメージ +50%。 |
| 栄枯Ⅲ | ダメージボーナス +20%、受ける燃焼ダメージ +20%。 |
| 栄枯Ⅳ | クリティカル率 +20%、クリティカルダメージ +30%、ダメージボーナス +20%。1回の攻撃で受けるダメージが最大HPの 80% を超えない。 |
| 常緑 | 持ち主の栄枯の段階が変化しない。 |
| 燃焼 | 被回復効果 −15%（重複しない）。ターン終了時、持ち主の攻撃力の 4% に等しいジェネシスダメージを与える。最大30スタックで1種の状態異常として数え、ダメージを与えるたびにスタック数が半分減る。 |
