エツィオの攻撃は【暗殺】として扱われ、自身のクリティカルテクニックが対象を 100 上回るごとに最終ダメージボーナスを得る。暗殺の発動、マークした敵への反撃、敵の撃破でシンクロ率をため、アルティメットで選んだ敵1体に連続攻撃を仕掛ける。主武器1つと副武器1つを携えて戦い、それらの効果は塑造2と塑造5で強化される。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 闇に生きる（単体攻撃） | リアルダメージ 400% | 600% | 1000% |
| 光に奉仕する（自己カウンター） | 敵1体に【ロックオン】、エツィオに【カウンター準備】1ターン | 2ターン | 3ターン |

- **闇に生きる**はどのランクでも暗殺として扱われる。
- **光に奉仕する**は、攻撃スペルの行動予定数が最も多い敵をマークする。

## アルティメット：信念が焼き付く時

エツィオは敵1体を選び、【結束の矢】または【結束の刃】で3回攻撃した後、【死は非道にあらず】で締めくくる。これらの攻撃対象は敵の効果で変更されない。

## 状態

| 状態 | 効果 |
| --- | --- |
| 暗殺 | 攻撃者のクリティカルテクニックが対象を 100 上回るごとに、その攻撃の最終ダメージボーナス +5%。 |
| ロックオン | 敵がエツィオに注意を向ける。チームへの一部の攻撃が優先的にエツィオへ向かう。 |
| カウンター準備 | 味方が攻撃を受けるたび、エツィオが【カウンターキル】で反撃する。再び得ると持続ターンが延び、解除されない。 |
| カウンターキル | リアルダメージ 500%。エツィオ自身が攻撃された場合はクリティカルダメージ +50%、他の味方のみが攻撃された場合は 500%。暗殺として扱われる。 |
| 結束の矢 | 単体攻撃：リアルダメージ 100%。対象のHPが 50% 未満ならさらに +50%。 |
| 結束の刃 | 単体攻撃：リアルダメージ 100%。対象のHPが 50% 以上ならさらに +50%。 |
| 死は非道にあらず | 単体攻撃：リアルダメージ 700%。 |
| ステルス暗殺 | クリティカルダメージ +30%、ダメージ軽減 +40%。 |
| 見習いアサシン | 8スタックに達すると【マスターアサシン】に変わる。他の味方もマスターアサシンを得て、暗殺の神秘学家はエツィオの効果の 70%、その他は 50% を得る。 |
| マスターアサシン | 暗殺時、クリティカルテクニックが対象を 100 上回るごとに、さらに最終ダメージボーナス +6%。 |
| アサシンマーク | 他の味方が持ち主に能動的にスペルを使うと、エツィオが1スタック消費してランク1の闇に生きるを追撃として発動する（マークは付かない）。最大5スタック。 |
| タカの導き | アルティメット発動時に消費する。2スタックごとに結束の矢または結束の刃の回数が1回増える。最大6スタック。 |
| 中毒 | 各ターン終了時、付与者の攻撃力に基づくジェネシスダメージを受ける。スタック可能。 |

結束の矢、結束の刃、死は非道にあらずはいずれも暗殺として扱われ、回避を無視し、ダメージ分担や追加ダメージを発動させない。

## 武器

エツィオは主武器（ヴェネツィア海賊の剣、傭兵隊長の戦鎚、船長の剣）を1つと、副武器（装飾付き短剣、肉屋のナイフ、スルタンのナイフ）を1つ装備する。塑造2で各主武器が強化される。

| 主武器 | 塑造2 |
| --- | --- |
| ヴェネツィア海賊の剣 | 対象に【アサシンマーク】を2スタック付与する。 |
| 傭兵隊長の戦鎚 | 他の味方がアルティメットを使った後、エツィオが【タカの導き】を2スタック得る。自身のアルティメット中、結束の矢、結束の刃、死は非道にあらずを1回発動するごとに最終ダメージボーナス +2.5%。 |
| 船長の剣 | スペルとアルティメットの攻撃にジェネシスダメージを追加する。量はランク1の闇に生きるまたは死は非道にあらずの基礎リアルダメージの 80% に、対象の中毒1つにつき 1.5%（10以上なら 2.5%）を加えた値。 |

塑造5で各組み合わせが強化される。

| 主武器 | 副武器 | 塑造5 |

| ヴェネツィア海賊の剣 | スルタンのナイフ | 追加行動のダメージボーナス +100%。カウンター準備とロックオンの持続延長が2ターンになる（グローバル版クライアントでは持続2ターン）。 |

| 0（予察） | モキシーの代わりにシンクロ率を使う。100% に達するとターン開始時にアルティメットが自動で発動し、他の方法では発動できない。スペルで暗殺を発動すると +5%、カウンターキルがロックオン状態の敵に命中すると +5%、攻撃対象を撃破すると +10%。 |
