モルダーはチーム全体が消費したモキシーから【戦備】をため、毎ターン開始時のスタック数が10、20、30に達すると味方への強化が開く。カウンタースペルは反撃を用意し、【決起】があればアルティメット、なければ過去に決別するで反撃する。アルティメットは味方全員に【礼儀・CRダメージ】を配り、アルティメットのクリティカルダメージを上げる。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 過去に決別する（単体攻撃） | リアルダメージ 100% | 150% | 250% |
| 明日を取り戻す（自己カウンター） | 戦備 2スタック | 3スタック | 5スタック |

- **過去に決別する**は攻撃後に対象へ【MPドレイン】を1スタック付与し、モルダーに1ターンの【連続行動Ⅰ】を与える。
- **明日を取り戻す**はさらにモルダーに1ターン、決起を持っていれば【強襲】、持っていなければ【奇襲】を与える。

## アルティメット：迷わぬ帰路

敵全員にリアルダメージ 400%、味方全員に礼儀・CRダメージを6スタック付与する。自ら発動した場合、敵全員に追加でリアルダメージ 300% を与える。反撃で発動した場合、戦備4スタックごとに味方全員へ礼儀・CRダメージを1スタック追加し、モルダーが2ターンの【教条】を得る。

## 状態

| 状態 | 効果 |
| --- | --- |
| 戦備 | ターン開始時のスタック数に応じて効果が発動する。最大50スタック、解除されない。 |
| 決起 | モキシーを得られなくなる【動揺】を無効化する。 |
| 強襲 | 味方が攻撃を受けると、モルダーがアルティメットで反撃する。発動すると消える。 |
| 奇襲 | 味方が攻撃を受けると、モルダーが奇襲を付与したスペルと同じランクの過去に決別するで反撃する。発動すると消える。 |
| MPドレイン | 持ち主が攻撃を受けると、攻撃者のモキシー +1、1スタック消費する。 |
| 連続行動Ⅰ | 行動回数 +1。 |
| 戦備駐屯 | 戦備1スタックごとにアルティメットの与ダメージ +2%。 |
| 武装整備 | クリティカル率 +30%。持ち主がアルティメットを発動するとき、上限を超えたクリティカル率がクリティカルダメージに変わる。 |
| 礼儀・CRダメージ | 1スタックごとにアルティメットのクリティカルダメージ +3%、最大100スタック。発動すると消える。解除されない。 |
| 教条 | アルティメット威力 +20%。持ち主は決起を得られなくなる。 |

## 狂想

狂想は洞察3のLv.30で開く。モルダーは4レベルの瞬想を1つ持ち、決起を味方全体へ広げ、カウンターを持続する反撃に変える。

| 瞬想 | レベル | 変化 |
| --- | --- | --- |
| 1 | 1 | 戦備が10スタック以上のとき、モルダーだけでなく味方全員が決起を得る。 |
| 1 | 2 | 戦備駐屯と武装整備が基本値の 20% 分上昇し、1スタックごとに 2.4%、クリティカル率 +36% になる（塑造2では 3% と +48%）。 |
| 1 | 3 | アルティメットが基本リアルダメージの 100% に等しい追加リアルダメージを与え、自ら発動しても反撃で発動しても追加ダメージと礼儀・CRダメージの追加スタックの両方を得る。過去に決別するは、攻撃前にモルダーが連続行動Ⅰを持っていれば基本ダメージの 100% に等しい追加リアルダメージを与え、MPドレインを2スタック付与する。 |
| 1 | 4 | 明日を取り戻すが2ターンの奇襲を付与する。奇襲は味方が攻撃を受けたあとに1ターン1回、過去に決別するで反撃し、モルダーが教条を持たないターン開始時に1ターンの強襲を与える。 |
