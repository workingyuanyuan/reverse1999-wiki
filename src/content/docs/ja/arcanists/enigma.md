エニグマは陣法【泳動電場】を育てる電力サポートである。毎ターン終了時に電力を泳動電場へ注入し、暗号文が注入量を上乗せして、注入した電力が50でLv.2、120でLv.3に上がる。スペルとループチェーンで味方全体のバリアを維持し、アルティメットで味方全員にクリティカルダメージと、消費した暗号文の数に応じて増えるダメージボーナスを与える。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 無限の変換（単体攻撃） | リアルダメージ 200%、味方全員に暗号文 3スタック | 300%、暗号文 4スタック | 500%、暗号文 5スタック |
| 思考の噛み合い（自己バフ） | 攻撃力の 280% 分のバリア | 420% | 700% |

- どちらのスペルも、どのランクでもエニグマに電力を 10 スタック与える。
- **思考の噛み合い**は、すでにバリアを持っていればその値に上乗せし、最大で攻撃力の 1250% 分まで重ねられる。このバリアがある間、味方全体で毎ターン最初の4回まで行動阻害を無効化する。

## アルティメット：世界の謎とその答え

エニグマに【解読機】を2ターン与え、味方全員のステータス低下、状態異常、行動阻害をすべて解除し、【ループチェーン】を5スタック得る。これで閉ループの原理が1回発動する。

## 状態

| 状態 | 効果 |
| --- | --- |
| 電力 | 最大 30 スタック。解除されない。 |
| 暗号文 | 泳動電場へ電力を注入するとき、所持者の暗号文スタック数と同じだけ追加で電力を注入し、暗号文は解除される。洞察1で上限が上がる前は最大 5 スタック。 |
| バリア | 味方へのダメージを吸収する。同時に攻撃を受けた味方が1体、2体、3体、4体以上のとき、バリア1点につきダメージを 1、1.2、1.5、1.8 吸収する。尽きるまで味方は敵のダメージでHPを失わない。シールドと同時に存在できない。 |
| 泳動電場 | 陣法。ターン開始時、注入された電力に応じてレベルが上がる。50以上でLv.2、120以上でLv.3になる。泳動電場が終わると注入された電力は失われる。 |
| 泳動電場Lv.1 | 味方全員のダメージボーナス +15%、3ターン。 |
| 泳動電場Lv.2 | 味方全員のスペル威力 +25%、ダメージボーナス +15%、3ターン。 |
| 泳動電場Lv.3 | 味方全員のアルティメット威力 +35%、スペル威力 +25%、ダメージボーナス +15%、2ターン。 |
| 泳動増幅 | 泳動電場Lv.3に入るとエニグマはモキシーを1得る。Lv.3の間、毎ターン開始時に味方全員が暗号文を3スタック得て、味方の攻撃は所持する電力1スタックごとにスペル威力 +0.4% を得る。さらにリアルダメージの味方は電力1スタックごとに追加で 6% のリアルダメージを与え、メンタルダメージの味方は電力1スタックごとにスペル威力をさらに +0.4% 得る。 |
| ループチェーン | 5スタックに達すると閉ループの原理を発動し、5スタック解除する。最大 9 スタック。 |
| 閉ループの原理 | 敵全員にリアルダメージ 200%、味方全員に暗号文を5スタック付与し、思考の噛み合いと同じ条件でエニグマの攻撃力の 280% 分のバリアを得る。その後、エニグマはモキシーを1、電力を5スタック得る。 |
| 解読機 | 味方全員のクリティカルダメージ +20%。さらに、それまでに味方全体で解除した暗号文1スタックごとにダメージボーナス +2%（最大 30 スタックまでカウント）。適用後にカウントはリセットされる。 |
