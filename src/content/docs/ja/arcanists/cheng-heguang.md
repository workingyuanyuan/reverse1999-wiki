程和光は【羽刃】をためてアルティメットを強化する。疾駆で得る力場【勠力同心】は味方全員の追加行動ダメージを上げ、他の味方が攻撃するたびに【断金】で追撃させる。アルティメットはすべての羽刃を消費する大技で、自身に行動ポイントを追加し、2ターンの間自身のスペル獲得を味方に譲る。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 裁風（単体攻撃） | リアルダメージ 200%、羽刃 1スタック | 300%、2スタック | 500%、3スタック |
| 疾駆（自己バフ） | 勠力同心 1スタック、2ターン | 2スタック、2ターン | 2スタック、3ターン |

## アルティメット：故に此の良い夜を

敵1体にリアルダメージ 1000% と羽刃による追加ダメージを与え、自身に【歩月登雲】と【連続行動Ⅰ】を2ターン付与する。攻撃後、すべての羽刃と自身のスペルを失い、モキシーを1と2ターンの勠力同心を2スタック得る。この攻撃は追撃とみなされる。

## 状態

| 状態 | 効果 |
| --- | --- |
| 羽刃 | 最大10スタック。1スタックごとにアルティメットのリアルダメージ +100%。5スタック以上でダメージボーナス +15%、アルティメットの貫通率 +30%。10スタックでアルティメットは行動ポイントを消費せず、必ずクリティカルになる。 |
| 勠力同心 | 【力場】効果。味方全員に追加行動ダメージボーナス +25% を与える（最大2スタック、持続ターンは個別計算）。他の味方が攻撃するたび、その攻撃のメインターゲットに断金で追撃する（1ターンに最大3回）。 |
| 断金 | 単体攻撃。リアルダメージ 300%。程和光が羽刃を1スタック得る。 |
| 歩月登雲 | チームのスペル獲得上限 −2。程和光が引くスペルはランダムな味方のスペルに変わり、リフレッシュでも自身のスペルは出ない。断金のリアルダメージ +150%、スペル威力 +10%。各ターン開始時、ランダムな敵1体に断金で追撃する。 |
| 連続行動Ⅰ | 行動ポイント +1。 |
| 力場 | 持ち主が他のキャラクターに与える効果。持ち主が場を離れると消える。 |
