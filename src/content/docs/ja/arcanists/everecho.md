エバーエコーは通常スペルと通常のアルティメットを持たず、チームがエネルギーカードでチャージした【術具】を通じて発動し、モキシーの代わりに同調値を使う。術具は味方全員に【在りし日の影】を与える攻撃と、【久しき光】を要する範囲回復を切り替え、さらにHPが1になったあとのダメージを肩代わりする【追憶】を味方全員に備えさせる。

## スペル

| スペル | 効果 |
| --- | --- |
| 在りし日の願い（範囲攻撃、損耗） | 敵全員にリアルダメージ 200%。味方全員に2ターンの【在りし日の影】を1スタック付与 |
| 明日への憧れ（範囲回復） | 味方全員のHPをエバーエコーの攻撃力の 180% 分回復。各味方からステータス低下、状態異常、行動阻害を2種類解除 |

- **明日への憧れ**は発動のたびに久しき光を1スタック消費する。残っていないと、術具は在りし日の願いに切り替わる。
- 【損耗】：術具がこのスペルを発動すると、そのターンの残りの間は停止する。

## エネルギーカード

| カード | 効果 |
| --- | --- |
| 光の息吹 | カオスエネルギー +1。エバーエコーが久しき光を1スタック得る。その後、術具がいつか、思い出の中でを選択していなければ、明日への憧れに切り替わる。 |
| 光の息吹Ⅱ | 光の息吹と同じで、カオスエネルギー +2 |
| カオスエネルギーⅡ | カオスエネルギー +2 |

## アルティメット：いつか、思い出の中で

敵全員にリアルダメージ 500%。その後、敵全員に3ターンの【抜け殻】、味方全員に2ターンの在りし日の影を5スタック、術具系の味方全員に3ターンの【懐かしき面影】を付与する。発動後、エバーエコーが久しき光を持っていれば術具は明日への憧れに、持っていなければ在りし日の願いに切り替わる。

| 在りし日の影 | エバーエコーの攻撃力の 0.6% に等しいダメージボーナスに加え、1スタックごとにダメージボーナス +1%。最大15スタックで、再び得ると持続ターンが更新される。 |

| 追憶 | HPが1まで下がると、残りのダメージを追憶が肩代わりする。最大値はエバーエコーの攻撃力の 400%。 |

| 抜け殻 | リアル防御力、メンタル防御力、クリティカル防御力 −10%。 |
| 懐かしき面影 | 持ち主の在りし日の影1スタックごとにクリティカルダメージ +2%。 |
