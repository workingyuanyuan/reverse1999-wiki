ウルリッヒは【電力】を集めて自身の陣法【泳動電場】に注入する。注入量が増えるにつれて泳動電場はレベル2、レベル3へと上がり、チーム全体の与ダメージとアルティメット威力を高める。2つのスペルはチャネルを開き、構造解析は敵のダメージ軽減を下げ、周波数解析は味方のアルティメット威力を上げる。すでにチャネル中であれば、代わりに電場へ電力を注入する。アルティメットはターン終了時に敵全員へ大ダメージを与える超演算解析を開き、【プライベートキー】のスタックが3つの解析すべてを強化する。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 識別モード（自己チャネル） | 構造解析に入る（3ターン）、同状態中の発動で礼儀・ULT威力 6スタック | 8スタック | 10スタック |
| ブラウンメロディー（自己チャネル） | 周波数解析に入る（3ターン）、同状態中の発動で礼儀・ULT威力 6スタック | 8スタック | 10スタック |

対応する解析がすでに発動している間に使うと、どちらのスペルもすべてのランクで電力を最大5まで泳動電場に注入する。

【礼儀・ULT威力】：1スタックごとにアルティメット威力 +3%、最大100スタック。解除されず、アルティメットが攻撃すると消費される。

## アルティメット：無限演算の和

ウルリッヒが【超演算解析】に1ターン入り、構造解析と周波数解析の持続ターンを1延ばし、電力を30得て、最大30の電力を泳動電場に注入する。

## 状態

| 状態 | 効果 |
| --- | --- |
| 電力 | 最大30スタック。解除されない。 |
| 泳動電場 | 注入された電力に応じてターン開始時にレベルが上がる陣法。50以上でレベル2、120以上でレベル3になる。終了すると注入された電力は消える。 |
| 泳動電場Lv.1 | 味方全員にダメージボーナス +15%、3ターン。 |
| 泳動電場Lv.2 | 味方全員にスペル威力 +25%、ダメージボーナス +15%、3ターン。 |
| 泳動電場Lv.3 | 味方全員にアルティメット威力 +35%、スペル威力 +25%、ダメージボーナス +15%、2ターン。 |
| 構造解析 | チャネル状態。ターン開始時に維持していれば、敵全員にダメージ軽減 −30% を1ターン付与し、内部のプライベートキー1つごとにさらに −4%。 |
| 周波数解析 | チャネル状態。ターン開始時に維持していれば、味方全員にアルティメット威力 +30% を1ターン付与し、内部のプライベートキー1つごとにさらに +4%。 |
| 超演算解析 | チャネル状態。ターン終了時に維持していれば、敵全員にリアルダメージ 600% と内部のプライベートキー1つごとに +100% を与える。この攻撃は追加行動とみなされ、チャネル中は行動できない。 |
| プライベートキー | 各解析が個別に保持するカウンターで、それぞれ最大10まで。対応する解析を強化する。 |
| ピーク電位 | 敵全員への攻撃。リアルダメージ 150%、さらに構造解析と周波数解析のプライベートキー1つごとに +15%。アルティメット威力が適用される。 |
| 泳動増幅 | 泳動電場がレベル3に達すると、ウルリッヒはモキシーを3得て、各解析がプライベートキーを5得る。電場がレベル3の間、新たに入る解析は即座にプライベートキーを5得て、超演算解析のプライベートキー1つごとにリアルダメージ +100% が加わる。 |

## 狂想

ウルリッヒの狂想は中国本土版にのみ実装されている。洞察3のLv.30で開き、4レベルの瞬想を1つ持つ。

| 瞬想 | レベル | 変化 |
| --- | --- | --- |
| 1 | 1 | 泳動増幅が電場のレベル3到達時に与えるモキシーが 4 になる。構造解析中に識別モードを使うと持続ターンが3延びる。構造解析のプライベートキー上限が5増え、デバフはターン開始時ではなくターン終了時に付与され、持続ターンが1延びる。 |
| 1 | 2 | 周波数解析中にブラウンメロディーを使うと持続ターンが3延びる。周波数解析のプライベートキー上限が5増え、バフはターン開始時ではなくターン終了時に付与され、持続ターンが1延びる。 |
| 1 | 3 | ピーク電位の発動時、構造解析または周波数解析のプライベートキーが10を超えていると、10を超える分を消費する。消費したキー1つごとに、電力タグを持ちリアルダメージを与える味方が攻撃時に与えるリアルダメージが 90% 増える（2ターン）。 |
| 1 | 4 | アルティメットの超演算解析の持続ターンが2延びる。チャネル中もウルリッヒは行動でき、各ターン終了時の攻撃前に、スペルエリアにある自身の通常スペルを可能な限り発動する。 |
