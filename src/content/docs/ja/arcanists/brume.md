グレイッシュブルーは自身のスペル、アルティメット、付与した燃焼から熱電効果のスタックをため、1ターンのチャネルで消費して追加行動攻撃を連続で放つ。1つ目のスペルは攻撃とチャネルのどちらかを選べ、2つ目はチーム全体を強化する。さらにチームで電力を注入して2段階で強化される泳動電場を配置する。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 左ハンドル・気ままな旅（単体攻撃） | メンタルダメージ 200% | 300% | 500% |
| 左ハンドル・長旅の計画（自己チャネル） | 熱電効果 10スタック | 15 | 20 |
| 真実の吐息（味方全体のバフ） | 熱電効果 10スタック | 15 | 20 |

- **左ハンドル**は1枚のカードで、使用時にそのランクで気ままな旅か長旅の計画を選ぶ。
- **気ままな旅**は命中後、グレイッシュブルーに【圧電結晶】を3ターン付与する。
- **長旅の計画**はグレイッシュブルーを1ターンのチャネル状態【宝石チャージ】にする。
- **真実の吐息**は味方全員に【真実の灼熱】を2ターン付与する。

## アルティメット：窮策ゆえの壮挙

敵1体にメンタルダメージ 750% を与え、グレイッシュブルーが熱電効果を10スタック得る。味方全員の真実の灼熱の持続が1ターン延びる。攻撃後、対象に【燃焼】10スタックと1ターンの【無賃乗車】を付与する。

## 状態

| 状態 | 効果 |
| --- | --- |
| 熱電効果 | チャネルで消費する。解除されない。 |
| 宝石チャージ | チャネル状態。ターン終了時まで維持していれば【寄り道の代償】を1回発動し、熱電効果を可能な限り消費する。10スタックごとに寄り道の代償1回あたりのメンタルダメージが +100% され、20スタックごとに発動回数が1回増える。1回のチャネルで消費できるのは最大 60スタック（追加発動2回、各回 +200%）まで。 |
| 寄り道の代償 | 敵1体にメンタルダメージ 200% と燃焼 3スタック。追加行動とみなされ、アルティメット威力が 100% 適用される。 |
| 終点到着 | 敵全員にメンタルダメージ 600% と燃焼 5スタック。追加行動とみなされ、アルティメット威力が 100% 適用される。 |
| 圧電結晶 | 寄り道の代償のメンタルダメージ +100%、終点到着のメンタルダメージ +200%。解除されない。 |
| 真実の灼熱 | ダメージボーナス +20%、スペル威力 +10%。メンタルダメージを与える味方はさらにスペル威力 +10%、アルティメット威力 +40% を得る。攻撃が命中するたび対象に2ターンの【偽装の熔解】を2スタック付与し、その攻撃が追加行動ならさらに2スタック付与する。 |
| 偽装の熔解 | 1スタックごとにクリティカル耐性率 −1%、クリティカル防御力 −3%。最大 20スタックで、各スタックの持続時間は独立している。 |
| 無賃乗車 | 寄り道の代償が所持者を優先して狙う。 |
| 燃焼 | 被回復効果 −15%（累積不可）。各ターン終了時、1スタックにつき所持者の攻撃力の 4% に等しいジェネシスダメージを与え、その後スタックが半分になる。最大 30スタックで、1つの状態異常とみなされる。 |
| 電力 | 最大 30スタック。解除されない。 |
| 泳動電場 | ターン開始時、注入された電力に応じてレベルが上がる：50以上でLv.2、120以上でLv.3。電場が消えると中の電力は失われる。 |
| 泳動電場Lv.1 | 味方全員のダメージボーナス +15%、3ターン。 |
| 泳動電場Lv.2 | 味方全員のスペル威力 +25%、ダメージボーナス +15%、3ターン。 |
| 泳動電場Lv.3 | 味方全員のアルティメット威力 +35%、スペル威力 +25%、ダメージボーナス +15%、2ターン。 |
| 泳動増幅 | 泳動電場Lv.3の開始時、グレイッシュブルーが熱電効果を20スタック得て、圧電結晶の持続が1ターン延びる。Lv.3の間、寄り道の代償のメンタルダメージ +400%。 |
