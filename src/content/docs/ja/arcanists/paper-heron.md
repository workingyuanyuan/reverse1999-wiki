鷺切は啓示編成の中核となる神秘学家である。味方が消費したひらめきは啓示となってスペルに配分され、啓示のついたスペルを使うとスペル行列の最後に即興スペルが追加され、集めた啓示に応じて強化される。予察によって即興スペルは敵2体へ分裂する木本源のリアルダメージに変わり、陣法【望気台】と【天機洞見】のレベルでさらに火力を伸ばす。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 魚龍変（敵2体への攻撃） | リアルダメージ 200% | 300% | 500% |
| 観気運（味方全体のバフ） | 即興スペルの与ダメージ +20% | +25% | +30% |

- **魚龍変**は攻撃後にひらめきを2消費し、そのターンの即興スペルの攻撃回数を1回増やす。
- **観気運**は鷺切に【谷風】を2スタック、味方全員に【景風】を2ターン付与し、ひらめきを2消費して表の与ダメージ上昇をそのターン中適用する。

## アルティメット：一紙、五軍に化す

鷺切がひらめきを2得たうえで敵全員にリアルダメージ 750% を与え、所持するひらめき1点ごとにアルティメット威力 +15% を得る。攻撃後、そのターンの即興スペルに啓示を8点加え、【天機洞見】を1レベル上げる。

## 状態

| 状態 | 効果 |
| --- | --- |
| 啓示 | 消費したひらめき1点ごとに1点たまる。毎ターン開始時にランダムなスペルへ最大5点ずつ配分され、使われなかったスペルの啓示はターン終了時に消える。啓示のついたスペルを使うと行列の最後に即興スペルが追加され、その啓示が蓄積される。 |
| 即興スペル | ランダムな敵1体にメンタルダメージ 200% と、蓄積された啓示1点ごとに 15% を与える。啓示が 3、6、12、20 点以上で攻撃回数がそれぞれ 1、2、3、5 回増える。ダメージは味方全員の平均ステータスで計算される。 |
| 望気台 | 陣法（敵味方合わせて場に同時に1つまで）。即興スペルが追加でリアルダメージ 50% を与え、ダメージボーナス +15% を得る。さらに敵が2体または1体のとき、追加で 25% または 50% を与える。1ターンの攻撃回数は最大3回で、超過分1回ごとにリアルダメージ 200% を追加し、最大4回まで数える。 |
| 天機洞見 | 望気台を強化するレベルで、下位レベルの効果を引き継ぐ。Lv.1：分裂攻撃の最終ダメージが下がらなくなる。Lv.2：敵が2体または1体のとき、追加でリアルダメージ 25% または 50%。Lv.3：追加でリアルダメージ 100%、貫通率 +15%、さらに敵が2体または1体のとき追加で 25% または 50%。Lv.3は4ターン続き、終わるとLv.2に戻る。Lv.3の間にレベルを上げると持続が更新される。望気台が消えて再配置されてもレベルは維持される。 |
| 谷風 | ターン開始時、鷺切が1スタックとひらめき2を消費し、そのターンの即興スペルの与ダメージを +20% する。 |
| 景風 | スペル威力 +20%、ダメージボーナス +20%。再び得ると持続ターンが延びる。 |
| 方術伝授 | 鷺切のバトル開始時の攻撃力の 15% に等しい攻撃力を得る。所持者がスペルを使うと、鷺切がひらめきを2消費し、そのターンの即興スペルに啓示を2点加える。解除されない。 |
