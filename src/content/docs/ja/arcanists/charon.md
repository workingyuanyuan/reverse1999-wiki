カローンは2つのスペル、チームの余剰モキシー、およびユニットの離脱から【ショック波】を集め、40スタック獲得するごとに【慄き】を1スタック得る。アルティメットはスペル枠にある自身のスペルをさらにショック波へ変え、各ターン終了時に懺悔の刻を放つチャネルに入る。一方、洞察1のパッシブはチームのために【泳動電場】を維持する。敵の【死の恐怖】と味方の【静魂】は、カローンが持つ慄きのスタック数に応じて強化される。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 虚無より来たり（敵全員への攻撃） | メンタルダメージ 200%、ショック波 20 | 300%、30 | 500%、50 |
| 死者の諫言（味方全体のバフ） | ショック波 20 | 30 | 50 |

どのランクでも、虚無より来たりは命中した敵に死の恐怖を、死者の諫言は味方全員に静魂をそれぞれ2ターン付与する。

## アルティメット：ひなげしが咲くとも

カローンはモキシーを1得て、スペル枠にある自身の虚無より来たりと死者の諫言をすべて取り除き、取り除いたカードのランクに応じて1枚につきショック波を20、30、50スタック得る。その後【往日の傷痕】に入る。往日の傷痕の間に再びアルティメットを使うと、増加するショック波の消費量がリセットされる。

## 状態

| 状態 | 効果 |
| --- | --- |
| 往日の傷痕 | 各ターン終了時、懺悔の刻を発動する。最初の1回はショック波を消費せず、発動するたびに次回の消費量が50スタック増える。カローンのショック波が不足するとチャネルが終わる。 |
| 懺悔の刻 | 敵全員にメンタルダメージ 150%、アルティメット威力の 60% が反映される。慄き1スタックごとにメンタルダメージ 50% と反映率 10% が追加される。カローンは所持するショック波5スタックにつき電力を1とモキシーを1得て、死の恐怖と静魂の持続ターンが1ターン延びる。 |
| ショック波 | カローンのチャネルで消費するスタック。 |
| 慄き | 1スタックごとに貫通率 +5%。最大10スタックで、各スタックが独自の持続ターンを持つ。 |
| 死の恐怖 | クリティカル防御力 −20%、さらにカローンの慄き1スタックにつき −5%（追加分は最大 −20%）。4スタック以上で被ダメージ +30%。持ち主が攻撃を受けてHPが付与時の最大HPの 20% を下回ると（上限はカローンの攻撃力の 4000%）、カローンが大量の【固定ジェネシスダメージ】を与える。 |
| 固定ジェネシスダメージ | ステータスボーナスの影響を受けないジェネシスダメージ。 |
| 静魂 | クリティカル率 +30%、さらにカローンの慄き1スタックにつき +5%（追加分は最大 +20%）。4スタック以上で、上限を超えたクリティカル率の 80% がクリティカルダメージに変わる。 |
| 泳動電場 | 注入された電力に応じてターン開始時にレベルが上がる。50でLv.2、120でLv.3になる。電場が終わると内部の電力は失われる。 |
| 泳動電場Lv.1 | 味方全員のダメージボーナス +15%、3ターン。 |
| 泳動電場Lv.2 | 味方全員のスペル威力 +25%、ダメージボーナス +15%、3ターン。 |
| 泳動電場Lv.3 | 味方全員のアルティメット威力 +35%、スペル威力 +25%、ダメージボーナス +15%、2ターン。 |
| 泳動増幅 | 泳動電場Lv.1が直接Lv.3へ上がるようになり、必要な電力が40になる。Lv.3に達すると、カローンと前に隣接する味方が【簡易アルティメット】を得る。Lv.3が維持されている間、カローンの貫通率 +50%。 |
| 簡易アルティメット | 次のアルティメットが行動ポイントを消費しない。アルティメットを自ら発動すると消える。 |
| 電力 | 最大30スタック。解除されない。 |
