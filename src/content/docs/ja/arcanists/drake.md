ドレイクは敵1体と自身に【燃焼】を積み、チームが付与する燃焼と光輪で共有ゲージの【残光】をためる。アルティメットは進度値をためるチャネルで、100 に達すると1ターンの【反逆の行い】に入り、自身の燃焼を残光へ変換したうえ、ゲージが一定の目盛りを超えるたびに【解き放たれし心火】を発動する。味方全体へのバフ【真実の意志】は、クリティカルダメージとドレイク自身のダメージボーナスの一部を味方に与える。

## スペル

| スペル | ランク1 | ランク2 | ランク3 |
| --- | --- | --- | --- |
| 一瞬の野火（単体攻撃） | メンタルダメージ 200%、燃焼 8スタック | 300%、10スタック | 500%、12スタック |
| ただ真を求めて（味方全体のバフ） | 味方全員に真実の意志 2ターン、ドレイクに燃焼 12スタック | 14スタック | 16スタック |

- **一瞬の野火**はどのランクでも対象に【クサリヘビの炎】を3ターン付与する。
- **ただ真を求めて**はドレイク自身に燃焼を付与するが、予察によりドレイクは燃焼ダメージを受けない。

## アルティメット：我が心は何処へ

ドレイクはチャネルを行い、【反逆の心】状態に入って進度値 +20 を得る。

## 状態

| 状態 | 効果 |
| --- | --- |
| 残光 | チーム共有のリソース。敵が燃焼か光輪を受けるたびに蓄積し、残る敵が少ないほど多くたまる。血の薪や看破の眼とは同時に持てない。 |
| 燃焼 | 被回復効果 −15%（重複しない）。ターン終了時、持ち主の攻撃力の 4% に等しいジェネシスダメージを受ける。最大30スタックで1つの状態異常として扱われ、発動するたびにスタックが半減する。 |
| クサリヘビの炎 | ダメージ軽減 −20%。持ち主が攻撃を受けるたびに燃焼が1スタック追加され、持ち主の燃焼スタック上限が 15 上がる。同時に持てるのは敵1体のみ。 |
| 真実の意志 | クリティカルダメージ +48%、ドレイクのダメージボーナスの 140% に等しいダメージボーナス（最大 78%）。再び得ると持続ターンが延びる。 |
| 反逆の心 | 進度値は 0 から始まり、チャネル中はモキシーを得ない。進度値が 100 に達すると、次のターン開始時に1ターンの反逆の行いに入り、自身の行動阻害をすべて解除する。 |
| 反逆の行い | ドレイクは行動阻害を無効化し、チームの残光上限が 250 上がる。ゲージが 200 を超えるごとに、任意の味方の行動後に解き放たれし心火を発動する。効果中は反逆の心を得られない。 |
| 解き放たれし心火 | 敵全員にメンタルダメージ 600%。対象の燃焼1スタックごとにスペル威力 +1%、残光 10 ごとにメンタルダメージ +20%。クサリヘビの炎を持つ対象に命中すると、対象とドレイクに燃焼を3スタック追加する。 |
