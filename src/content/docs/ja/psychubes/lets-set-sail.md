## 効果

**増幅1**：記憶者が【ステータス低下】の敵を攻撃した時、クリティカルダメージが14%アップする。

**増幅2**：記憶者が【ステータス低下】の敵を攻撃した時、クリティカルダメージが17.5%アップする。

**増幅3**：記憶者が【ステータス低下】の敵を攻撃した時、クリティカルダメージが21%アップする。

**増幅4**：記憶者が【ステータス低下】の敵を攻撃した時、クリティカルダメージが24.5%アップする。

**増幅5**：記憶者が【ステータス低下】の敵を攻撃した時、クリティカルダメージが28%アップする。
