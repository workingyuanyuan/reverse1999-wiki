## 召喚

★6の基礎確率は 1.5%。60回連続で★6が出ないと確率が上がり、70回目までに★6が確定する。回数を次へ引き継ぐのは期間限定キャラ召喚のみで、限定召喚、コラボ召喚、多くのイベント召喚は終了時にリセットされる：[召喚と天井](/ja/systems/summoning/)。

## 用語

| 用語 | 意味 |
| --- | --- |
| 本源 | 神秘学家のタイプ。星、岩、獣、木、霊、知の6種。 |
| 洞察 | 3段階（I、II、III）の昇格。段階ごとにレベル上限が上がり、伝承のパッシブが1つ開く。 |
| 塑造 | 5回の強化。1回ごとに同じ神秘学家の重複1体を使う。 |
| 狂想 | 一部の神秘学家にある後続の強化。洞察3のLv.30で開き、4レベルずつの瞬想を2つ持つ。 |
| モキシー | たまるとアルティメットを使えるようになるポイント。 |
