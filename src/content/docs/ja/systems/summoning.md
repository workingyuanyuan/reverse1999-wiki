| レア度 | 基礎確率 |
| --- | --- |
| ★6 | 1.5%（天井込みの総合確率 2.36%） |
| ★5 | 8.5% |
| ★4 | 40% |
| ★3 | 45% |
| ★2 | 5% |

湖の契約を除くすべての召喚でこの確率が使われ、どの召喚でも10回召喚ごとに★4以上の神秘学家が少なくとも1体出現する。

## 天井

- 60回連続で★6が出ない場合、61回目の召喚では★6の確率が 4% になる。
- その後、★6が出ない召喚が1回増えるごとに、その確率に 2.5% が加算される。
- ★6が出ないまま70回目の召喚に達すると、必ず★6が出現する。
- ★6を獲得すると、同じ種類の召喚では確率が 1.5% に戻り、★6未出現の回数もリセットされる。

## ピックアップとすり抜け

ピックアップ★6が1体の召喚では、出現した★6がピックアップ神秘学家になる確率は 50% である。別の神秘学家が出た場合（すり抜け）、次に出現する★6はその召喚のピックアップ神秘学家になる。ピックアップ★5が2体の召喚では、出現した★5が2体のいずれかになる確率は 50% で、各キャラの確率は等しい。

プレイヤーがピックアップ神秘学家を選ぶ召喚でも、選んだ神秘学家に対して同じ仕組みが働く。一部のイベント召喚では割合が異なる：湖の啓示（選択★6が2体）は 70%、湖の豊穣（ピックアップ★6が4体）と湖の贈り物（選択★6が3体）は 100%。

## 召喚の種類ごとの引き継ぎ

| 召喚の種類 | 確定回数 | 召喚終了時 | ピックアップ★6 |
| --- | --- | --- | --- |
| 期間限定キャラ召喚（限时角色征集） | すべての期間限定キャラ召喚で共有 | 回数と上昇した確率を次の期間限定キャラ召喚へ引き継ぐ | 50%、外れた場合は次が確定 |
| 湖のさざ波、湖の切望（★6を1体選択） | 同名の召喚同士で共有 | 次の同名召喚へ引き継ぐ | 最初の★6は選択したキャラ、以降は 50% で次が確定 |
| 常設キャラ召喚、湖の中央（常驻角色征集） | 独自 | 常設の召喚 | ピックアップなし |
| 朔日祭限定召喚、周年限定召喚、パレード限定召喚 | 独自、次回の同種召喚とは共有しない | リセット | 50%、外れた場合は次が確定 |
| プレイヤーが★6を選ぶ限定復刻召喚（限定复刻自选征集） | 独自 | リセット | 50%、外れた場合は次が確定 |
| コラボ召喚 | 独自 | リセット | 50%、外れた場合は次が確定 |
| その他の期間限定イベント召喚（湖の豊穣、湖の契約、湖の啓示、湖の贈り物、湖の約束、朔日の飛雪） | 独自 | リセット | 各召喚のルールどおり |

朔日祭限定召喚、周年限定召喚、パレード限定召喚の神秘学家は他の種類の召喚には追加されず、後の同種召喚か限定復刻召喚で再登場する。これらの召喚では1回ごとにシークレットボイスを1個獲得し、召喚ショップで限定神秘学家、ピックアップ★5、または素材と交換できる。シークレットボイスはショップ終了時に期限切れとなる。

召喚の種類は、ルールに括弧で示された種類で決まる（例：【限时角色征集】）。期間限定イベント召喚（限时活动征集）という名前の召喚の一部は期間限定キャラ召喚の種類に属し、回数を共有する。ほかのイベント召喚は共有しない。

期間限定キャラ召喚の引き継ぎルールが挙げるのは、召喚回数と上昇した★6確率である。すり抜け後の確定は、その召喚のピックアップキャラを指す（中国語の原文では「本期」）。

## 独自ルールの召喚

| 召喚 | ルール |
| --- | --- |
| 最初の一滴（第一滴雨）、初心者向け召喚 | 最大30回召喚、30回以内に★6確定 |
| 湖の契約（湖的许诺） | 30回以内に金のかせを1個獲得、最大60回召喚。召喚終了前に金のかせを開いて★6を1体選択 |
| 金の糸車（金纺轮） | バージョン 2.2 の湖の中央プールから模擬10連召喚を行うアイテム。毎回★6が少なくとも1体含まれ、どの天井回数にも数えない |
| コラボ召喚 | 100回目、160回目、220回目、280回目の召喚で追加報酬：コラボ神秘学家1体、またはその神秘学家と別の報酬からの選択 |

## 重複時の変換

| 神秘学家 | 2〜6体目 | 7体目以降 |
| --- | --- | --- |
| ★6 | その神秘学家の肖像 ×1 + 大容量ロストボイス ×12 | 大容量ロストボイス ×28 + プネウマ現像液 ×10 |
| ★5 | 肖像 ×1 + 大容量ロストボイス ×3 | 大容量ロストボイス ×7 |
| ★4 | 肖像 ×1 + ロストボイス ×8 | ロストボイス ×12 |
| ★3 | 肖像 ×1 + ロストボイス ×4 | ロストボイス ×7 |
| ★2 | 肖像 ×1 + ロストボイス ×3 | ロストボイス ×5 |

2〜6体目で得る肖像は、その神秘学家の[塑造](/ja/arcanists/sonetto/#塑造)を上げるために使う。召喚、銀行、配布のいずれから得た重複にも同じ変換が適用される。
