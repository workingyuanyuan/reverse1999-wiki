## ターン

リバース：1999 のバトルはターン制で進む。毎ターン、チームはスペルカードの手札と、それに使う行動回数を得る。敵は自分の行動回数で行動する。ダメージは攻撃側と対象の本源、ダメージタイプ、下記のステータスで決まる。

## 本源の相性

| グループ | 有利な相手 |
| --- | --- |
| 獣 | 木 |
| 木 | 星 |
| 星 | 岩 |
| 岩 | 獣 |
| 霊と知 | 独自の相性（霊知有利） |

最初のグループはゲーム内で自然有利と呼ばれる。本源の相性で劣る敵を攻撃すると、どちらのグループでも与えるダメージが 30% 増える。このボーナスはダメージボーナスとは別に計算される。

## ダメージタイプ

| タイプ | 軽減するもの |
| --- | --- |
| リアルダメージ | 対象のリアル防御力 |
| メンタルダメージ | 対象のメンタル防御力 |
| ジェネシスダメージ | なし。すべての防御力とダメージ軽減を無視する固定ダメージで、ダメージボーナスの恩恵もほとんど受けない |

神秘学家はそれぞれリアルダメージかメンタルダメージを与える。ジェネシスダメージは燃焼や中毒などの状態と、一部のスキルから生じる。ダメージタイプは行動阻害にも関わる。リアルダメージの攻撃は石化を、メンタルダメージの攻撃は氷結を解く（[状態効果](/ja/systems/statuses/)を参照）。

## スペルと行動回数

- 場に4人（サポートを含む）いるとき、手札のスペルは最大7枚。上限は生存して出撃している人数によって変わる。
- スペルを使うか、手札のスペルを移動すると、行動を1回消費する。同じスペルの上にカードを移動するとランクが上がり、ランク3が最大。ランクが高いほど強い。
- 味方の残りが少ないと、毎ターンの行動回数は減るが、高ランクのスペルを得やすくなる。同じように、敵を倒すと敵の行動回数が減る。
- そのターンに使ったカードは、ターンが進む前に行動エリアをタップすれば取り消せる。

## モキシーとアルティメット

モキシーはアルティメットに使うリソースである。神秘学家はスペルを使ったり移動したりすることで、また一部のスキルでモキシーを得る。

- 実装済みの神秘学家138人のうち131人は、アルティメットにモキシーが5必要。
- アレクシオス、エツィオ、カサンドラ、コッペリア、エバーエコー、双子、ヘドネは代わりに別のリソースをためる。
- 動揺を受けた神秘学家はモキシーを獲得できない。一部の敵と神秘学家はモキシーを減らす。

## ステータス

| ステータス | 効果 |
| --- | --- |
| HP | 0になるとバトルから離脱する |
| 攻撃力 | 攻撃が与えるダメージの基礎 |
| リアル防御力 | 受けるリアルダメージを減らす |
| メンタル防御力 | 受けるメンタルダメージを減らす |
| クリティカルテクニック | クリティカル率とクリティカルダメージを上げる |
| クリティカル率 | クリティカルが発生する確率。回復がクリティカルになる確率でもある |
| クリティカル耐性率 | クリティカルを受ける確率を下げる |
| クリティカルダメージ | クリティカル時のダメージ。クリティカル回復の回復量にも効くが、効果は逓減する |
| クリティカル防御力 | 受けるクリティカルのダメージを減らす |
| ダメージボーナス | 与えるダメージを上げる |
| ダメージ軽減 | 受けるダメージを減らす |
| 貫通率 | 対象のリアル防御力とメンタル防御力の一部を無視する |
| スペル威力 | スペルのダメージを上げる |
| アルティメット威力 | アルティメットのダメージを上げる |
| 回復率 | 与える回復量を上げる |
| 再生率 | ターン開始時、前のターンに受けたダメージの一部を回復する |
| HP吸収率 | 与えたダメージの一部を攻撃者のHPに変える |
| ジェネシスダメージボーナス | 与えるジェネシスダメージを上げる |
