라모나는 퇴마 의뢰 스택을 모은다. 매 턴 시작 때 이 스택을 소모해 그 수만큼 아군 주문을 영혼 빙의로 덮어쓰고, 아군이 덮어쓴 주문을 사용할 때마다 모든 적에게 중독과 퇴마제를 거는 추격 공격인 마리골드 방식을 발동한다. 퇴마제는 중독을 추가로 결산시키며, 최종 술식은 각 적의 중독을 매 턴 커지다가 끝날 때 터지는 영혼 클리너로 바꾼다.

## 주문

| 주문 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- |
| 정화의 향 (적 2명 공격) | 정신 피해 180% | 270% | 450% |
| 망령 접근 금지 (단일 공격) | 정신 피해 200%, 중독 100%로 1회 결산 | 300%, 125% | 500%, 160% |

- 두 주문 모두 각 대상에게 2턴 동안 [중독] 1개를 부여하며, 매 턴 종료 시 라모나 공격의 40%에 해당하는 고정 피해를 준다.
- **정화의 향**은 공격 뒤 라모나에게 [퇴마 의뢰] 1스택을 부여한다.
- **망령 접근 금지**는 대상의 중독 1턴분을 표에 나온 비율의 피해로 즉시 결산하며, 중독의 남은 턴을 줄이지 않는다.

## 최종 술식: 두 세계에 안식을

모든 적에게 정신 피해 500%를 주고, 각 대상의 중독을 최대 6개까지 2턴 동안 지속되는 [영혼 클리너] 1개로 바꾼다. 이후 라모나가 [집중 퇴마]를 2턴 동안 얻는다.

## 상태

| 상태 | 효과 |
| --- | --- |
| 중독 | 턴 종료 시 보유자가 시전자 공격에 비례한 고정 피해를 받는다. 중첩된다. |
| 퇴마 의뢰 | 턴 시작 시 제거되어 라모나의 선각을 발동한다. 최대 6스택. |
| 영혼 빙의 | 주문을 1턴 동안 덮어쓴다. 아군이 이 주문을 직접 사용하면 라모나가 [마리골드 방식]을 1회 시전한다. 다른 덮어쓰기 효과와 겹치지 않는다. |
| 마리골드 방식 | 추격 공격이다. 모든 적에게 정신 피해 250%와 중독 1개(공격의 40%, 2턴)를 주고, 명중한 각 대상에게 [퇴마제] 1스택을 2턴 동안 부여한다. |
| 퇴마제 | 턴 종료 시 스택마다 보유자의 중독을 지속 턴을 줄이지 않고 1회 추가로 결산한다. 최대 6스택이며, 각 스택의 지속 시간은 따로 계산한다. |
| 영혼 클리너 | 중독으로 간주된다. 턴 종료 시 흡수한 중독 개수 × 공격의 50%에 해당하는 고정 피해를 주며, 지속된 턴마다 피해가 25%씩 늘어난다. 지속 시간이 끝나면 지속된 턴 수 × 공격의 350%에 해당하는 고정 피해를 추가로 주며, 이 피해는 중독 피해로 간주된다. |
| 집중 퇴마 | 매 턴 시작 시 라모나가 영혼 빙의로 덮어쓴 3단계 망령 접근 금지를 예비 주문으로 얻는다. 해제되지 않으며, 다시 얻으면 지속 시간이 늘어난다. |

## 형상

| 형상 | 변화 |

| 1 | 통찰 3이 전투에 들어갈 때 열정 +3을 준다. 마리골드 방식이 400%를 주고 중독 2개와 퇴마제 2스택을 부여한다. |
| 2 | 영혼 클리너가 흡수한 중독 개수 × 공격의 75%를 주고, 턴마다 35%씩 늘어나며, 끝날 때 지속된 턴 수 × 공격의 550%를 준다. 집중 퇴마가 3턴 동안 지속된다. |
| 3 | 정화의 향과 망령 접근 금지가 중독 2개를 부여한다. 라모나가 부여하는 모든 중독이 공격의 50% 피해를 준다. |
| 4 | 망령 접근 금지가 단계에 따라 중독을 140%, 165%, 200%로 결산한다. 영혼 클리너가 끝날 때 지속된 턴 수 × 공격의 750%를 준다. |
| 5 | 영혼 클리너가 흡수한 중독 개수 × 공격의 100%를 주고, 턴마다 45%씩 늘어난다. 라모나가 매 턴 퇴마 의뢰 2스택을 얻는다. 마리골드 방식의 퇴마제가 최대 8스택까지 쌓인다. |
