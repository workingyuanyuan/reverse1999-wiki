## 주문

### 정화의 향

**1단계**: 광역 공격, 적군 2명에게 180%의 정신 피해를 줌, 목표에게 2턴간 \[중독\] 1개 부여, 턴 종료 시마다 목표에게 사용자 공격×40%의 고정 피해를 줌.

공격 후 자신에게 \[퇴마 의뢰\] 1스택 부여

**2단계**: 광역 공격, 적군 2명에게 270%의 정신 피해를 줌, 목표에게 2턴간 \[중독\] 1개 부여, 턴 종료 시마다 목표에게 사용자 공격×40%의 고정 피해를 줌.

공격 후 자신에게 \[퇴마 의뢰\] 1스택 부여

**3단계**: 광역 공격, 적군 2명에게 450%의 정신 피해를 줌, 목표에게 2턴간 \[중독\] 1개 부여, 턴 종료 시마다 목표에게 사용자 공격×40%의 고정 피해를 줌.

공격 후 자신에게 \[퇴마 의뢰\] 1스택 부여

### 망령 접근 금지

**1단계**: 단일 공격, 200%의 정신 피해를 줌, 목표에게 2턴간 \[중독\] 1개 부여, 턴 종료 시마다 목표에게 사용자 공격×40%의 고정 피해를 줌. 목표 1턴 \[중독\] 효과를 기존 피해의 100%로 즉시 결산, 이 결산은 지속 턴을 감소시키지 않음

**2단계**: 단일 공격, 300%의 정신 피해를 줌, 목표에게 2턴간 \[중독\] 1개 부여, 턴 종료 시마다 목표에게 사용자 공격×40%의 고정 피해를 줌. 목표 1턴 \[중독\] 효과를 기존 피해의 125%로 즉시 결산, 이 결산은 지속 턴을 감소시키지 않음

**3단계**: 단일 공격, 500%의 정신 피해를 줌, 목표에게 2턴간 \[중독\] 1개 부여, 턴 종료 시마다 목표에게 사용자 공격×40%의 고정 피해를 줌. 목표 1턴 \[중독\] 효과를 기존 피해의 160%로 즉시 결산, 이 결산은 지속 턴을 감소시키지 않음

## 최종 술식: 두 세계에 안식을

광역 공격, 모든 적군에게 500%의 정신 피해를 줌, 목표가 보유한 최대 6개의 중독을 \[영혼 클리너\] 1개로 전환, 2턴간 지속.

공격 후 자신에게 \[집중 퇴마\] 부여, 2턴간 지속

## 계승

\[영혼 빙의\]로 덮어쓰기된 주문 직접 사용 시 라모나가 \[마리골드 방식\] 1회 시전

## 형상

**형상 1**: **선각** 전투 진입 시 자신이 획득하는 열정이 3으로 증가. \[마리골드 방식\]이 주는 정신 피해 400%로 증가, 추가되는 \[중독\] 개수 2개로 증가, 추가되는 \[퇴마제\] 스택 2로 증가

**형상 2**: **두 세계에 안식을** \[영혼 클리너\] 결산 시 주는 고정 피해가 전환 시 소모한 \[중독\] 개수×사용자 공격×75%로 증가, 1턴 존재할 때마다 결산 피해 증폭이 35%로 증가. 지속 시간 종료 시 주는 고정 피해가 존재한 턴 수×사용자 공격×550%로 증가

\[집중 퇴마\] 지속 턴 수가 3으로 증가

라모나가 부여하는 모든 \[중독\] 고정 피해가 사용자 공격×50%로 증가

**형상 4**: **망령 접근 금지** 주문 1/2/3 단계 시 결산되는 \[중독\] 피해 계수가 140/165/200%로 증가

**두 세계에 안식을** \[영혼 클리너\] 지속 시간 종료 시 주는 고정 피해가 존재한 턴 수×사용자 공격×750%로 증가

**형상 5**: **두 세계에 안식을** \[영혼 클리너\] 결산 시 주는 고정 피해가 전환 시 소모한 \[중독\] 개수×사용자 공격×100%로 증가, 1턴 존재할 때마다 결산 피해 증폭이 45%로 증가

## 상태

- **중독**: 턴 종료 시 사용자 공격에 따른 고정 피해를 받음(중첩 가능)
- **퇴마 의뢰**: 턴 시작 시 제거되며 특수 효과 발동(최대 6스택)
- **영혼 클리너**: 중독으로 간주. 턴 종료 시 전환 시 소모된 \[중독\] 수량×사용자 공격×50%의 고정 피해를 받음. \[영혼 클리너\]가 1턴 존재할 때마다 결산 피해 25% 증가. 지속 시간 종료 시 존재한 턴 수×사용자 공격×350%의 추가 고정 피해를 줌(중독 피해로 간주)
- **집중 퇴마**: 턴 시작 시 \[영혼 빙의\]로 덮어써진 3단계 예비 주문-망령 접근 금지 1장 생성(해제 불가, 중복 획득 시 지속 시간 중첩)
- **영혼 빙의**: 주문 표면 덮어쓰기, 아군이 \[영혼 빙의\]로 덮어써진 주문 직접 사용 후 라모나가 \[마리골드 방식\] 1회 시전, \[영혼 빙의\] 덮어쓰기 효과 1턴간 지속(다른 주문 표면 덮어쓰기 효과와 중첩 불가)
- **마리골드 방식**: 광역 공격, 모든 적군에게 250%의 정신 피해를 줌, 목표에게 2턴간 \[중독\] 1개 부여, 턴 종료 시마다 목표에게 사용자 공격×40%의 고정 피해를 줌. 공격 명중 후 목표에게 \[퇴마제\] 1스택 부여, 2턴간 지속.

  이번 공격은 추격 1회로 간주
- **퇴마제**: 턴 종료 시 \[퇴마제\] 1스택당 목표의 \[중독\] 1회 추가 결산(이 결산은 지속 턴을 감소시키지 않음, 최대 6스택, 스택별 지속 시간 개별 계산)
