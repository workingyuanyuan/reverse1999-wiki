## 주문

### 체술 낭송

**1단계**: 단일 공격, 180%의 정신 피해를 줌. 직접 시전 후 \[토성\] 1개 획득, 1개를 보유할 때마다 방어 무시율 +6%. \[행성\] 최대치는 3.

**2단계**: 단일 공격, 270%의 정신 피해를 줌. 직접 시전 후 \[토성\] 2개 획득, 1개를 보유할 때마다 방어 무시율 +6%. \[행성\] 최대치는 3.

**3단계**: 단일 공격, 450%의 정신 피해를 줌. 직접 시전 후 \[토성\] 3개 획득, 1개를 보유할 때마다 방어 무시율 +6%. \[행성\] 최대치는 3.

### 오래된 관측법

**1단계**: 광역 공격, 적군 2명에게 135%의 정신 피해를 줌. 직접 시전 후 \[화성\] 1개 획득, 1개를 보유할 때마다 흡혈률 +6%. \[행성\] 최대치는 3.

**2단계**: 광역 공격, 적군 2명에게 200%의 정신 피해를 줌. 직접 시전 후 \[화성\] 2개 획득, 1개를 보유할 때마다 흡혈률 +6%. \[행성\] 최대치는 3.

**3단계**: 광역 공격, 적군 2명에게 335%의 정신 피해를 줌. 직접 시전 후 \[화성\] 3개 획득, 1개를 보유할 때마다 흡혈률 +6%. \[행성\] 최대치는 3.

## 최종 술식: 유일한 완벽함

단일 공격, 모든 \[행성\] 제거 후 600%의 정신 피해를 주고 \[만월\] 2개 획득, 1개를 보유할 때마다 마법 위력 +6%. \[행성\] 최대치는 3.

## 상태

- **토성**: 방어 무시율 증가
- **행성**: 토성, 화성, 만월은 모두 행성으로 최대치를 공유한다. 각 행성 효과는 중첩 가능, 해제 불가.
- **화성**: 흡혈률 증가
- **만월**: 마법 위력 증가
- **토성 점술**: 방어 무시율 +12%(효과 중첩 가능, 공격 후 전부 소모)
- **화성 점술**: 흡혈률 +12%(효과 중첩 가능, 공격 후 전부 소모)
- **만월 점술**: 마법 위력 +12%(효과 중첩 가능, 일반 주문 사용 후 소모)
- **체술 낭송**: 단일 공격
- **오래된 관측법**: 광역 공격
- **주문 강화Ⅱ**: 턴 시작 시 랜덤 2장의 주문 단계 +1
- **응결된 빛**: 최종 술식 위력과 추격 피해 보너스 +4%(효과 중첩 가능, 최대 10스택, 해제 불가)
