코너스톤은 아군이 줄인 피해를 모아 반격에 쏟아붓는다. 자신이 전장에 있는 동안 모든 아군이 타당성 검토를 지니며, 피격마다 줄어든 피해가 시행착오 포인트로 쌓인다. 다른 아군이 반격할 때 이 저장량에서 추가 현실 피해가 나가고, 적 턴 종료 때 발동하는 자신의 피드백 공격은 저장량을 비워 추가 피해를 준다. 아군의 추가 행동은 아이디어 개선을 쌓고, 이것이 최종 술식을 강화하는 설계 업그레이드 스택으로 바뀐다.

## 주문

| 주문 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- |
| 구성 실천 (단일 공격) | 현실 피해 200%, 검수 공정 중 +200% 및 치명타 피해 +40% | 300%, +300%, +60% | 500%, +500%, +100% |
| 형상과 배경의 관계 (자신 카운터) | [검수 공정] 2턴, [아이디어 개선] 2스택 | 2턴, 3스택 | 2턴, 5스택 |

구성 실천은 모든 단계에서 반격으로 취급된다. 형상과 배경의 관계로 얻는 아이디어 개선 스택은 2턴 동안 지속된다.

## 최종 술식: 이곳이 비전의 초석

자신 카운터. 코너스톤이 [납품 공정]에 1턴 동안 들어가며, 적 턴 종료 시 납품 피드백이 발동한다.

## 상태

| 상태 | 효과 |
| --- | --- |
| 타당성 검토 | 코너스톤이 전장에 있는 동안 모든 아군이 보유한다. 적 공격의 고정 피해가 아닌 피격마다 코너스톤이 전투에 들어갈 때의 공격의 최대 80%만큼 피해를 줄이고, 줄인 양을 시행착오로 저장한다. |
| 시행착오 | 코너스톤의 피해 저장량으로, 전투에 들어갈 때의 공격의 최대 500%까지 쌓인다. 다른 아군이 반격할 때마다 코너스톤 공격의 100%에 해당하는 현실 피해를 추가하며, 저장량이 찬 비율의 100%만큼 이 피해가 오른다. 저장량이 가득 차면 더 쌓이지 않지만, 타당성 검토의 피해 감소는 계속 적용된다. |
| 검수 공정 | 매 적 턴 종료 시 코너스톤이 제어 상태여도 검수 피드백을 시전한다. 다시 얻으면 지속 시간이 늘어나며, 해제되지 않는다. |
| 검수 피드백 | 모든 적에게 현실 피해 1000%를 주고, 코너스톤이 설계 업그레이드 1스택과 열정 1을 얻는다. 시행착오를 모두 비우며, 비운 1000포인트마다 현실 피해 100%를 추가로 준다. 반격으로 취급된다. |
| 납품 공정 | 타당성 검토가 피격마다 전투 진입 시 공격의 최대 160%까지 피해를 줄인다. 적 턴 종료 시 제어 상태여도 납품 피드백을 시전하며, 그 턴에는 검수 공정이 발동하지 않는다. 다시 얻으면 지속 시간이 늘어나며, 해제되지 않는다. |
| 납품 피드백 | 모든 적에게 현실 피해 2000%를 주고 열정 1을 얻는다. 시행착오를 모두 비워 1000포인트마다 현실 피해 100%를 추가로 준다. 설계 업그레이드가 5스택 이상이면 5스택을 써서 현실 피해 1000% 추가, 술식 위력 +75%, 방어 무시율 +20%를 얻고, 5스택 미만이면 3스택을 얻는다. 반격으로 취급되며 검수 공정의 지속 시간을 1턴 늘린다. |
| 아이디어 개선 | 스택마다 반격 피해 보너스 +4%, 마법 위력 +4%. 최대 20스택이며 스택마다 지속 시간이 따로 계산되고, 해제되지 않는다. |
| 설계 업그레이드 | 납품 피드백이 소모하는 스택. 최대 10스택이며 해제되지 않는다. |
| 제어 | 행동을 막는 효과. 기절, 석화, 악몽, 빙결, 무장 해제, 침묵, 봉인이 여기에 속한다. |
