코르부스는 팀 아래에 술진 [전기장 폭주]를 유지하며, 첫 레벨은 직접 깐다. 코르부스가 행동할 때마다 [전력]을 얻고, 추가 공격 [폭력 봉합]이 그 전력을 술진에 주입한다. 술진은 Lv.2와 Lv.3으로 오르며, 레벨이 오를수록 아군 모두를 더 강하게 버프한다. 주문은 코르부스에게 공격을 올리는 [아크 라이트] 스택을 주고, 적에게 [균열점]을 건다. 폭력 봉합은 균열점을 소모해 보너스 효과를 낸다.

## 주문

| 주문 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- |
| 아크 연선 (단일 공격) | 정신 피해 200%, 아크 라이트 2스택 | 300%, 4스택 | 500%, 8스택 |
| 장밋빛 균열 (자신 음송) | 대상에게 이미 고온 용접이 있으면 아크 라이트 2스택 | 4스택 | 8스택 |

- **아크 연선**은 모든 단계에서 공격한 대상에게 균열점을 1스택 준다.
- **장밋빛 균열**은 코르부스를 [봉합] 상태로 2턴 동안 만들고, 대상 적에게 [고온 용접]을 건다. 대상에게 이미 고온 용접이 있으면 코르부스가 표의 아크 라이트도 얻고, 대상은 균열점을 1스택 받는다.

## 최종 술식: 시간을 영원에 봉합

적 하나에게 정신 피해 700%를 주고, 균열점을 1스택 준 뒤 폭력 봉합을 한 번 발동한다. 최종 술식은 팀이 뽑는 주문 수 제한에 포함되지 않는다.

## 폭력 봉합

추가 행동으로 치는 단일 공격이다. 정신 피해 400%를 주고, 술식 위력을 100% 비율로 적용받으며, 전력을 최대 20스택까지 전기장 폭주에 주입한다. 그 밖의 효과는 술진의 레벨에 따라 다르다. 균열점 열의 보너스는 대상에게 균열점이 1스택 있어야 하며, 그 스택을 소모한다.

| 술진 레벨 | 추가 피해 | 균열점이 있을 때 |
| --- | --- | --- |
| Lv.1 | 없음 | 코르부스가 아크 라이트 3스택을 얻는다 |
| Lv.2 | 정신 피해 +200% | 코르부스가 가진 아크 라이트 1스택마다 정신 피해 +5% |
| Lv.3 | 정신 피해 +600% | 코르부스가 가진 아크 라이트나 진동 아크 1스택마다 정신 피해 +5%, 술식 위력 적용 비율 +0.3% |

## 상태

| 상태 | 효과 |
| --- | --- |
| 전기장 폭주 | 술진. 턴 시작 때 주입된 전력에 따라 오른다. 50 이상이면 Lv.2, 120 이상이면 Lv.3이 된다. 술진이 끝나면 그 안의 전력은 사라진다. |
| 전기장 폭주 Lv.1 | 아군 전체 피해 보너스 +15%, 3턴. |
| 전기장 폭주 Lv.2 | 아군 전체 마법 위력 +25%, 피해 보너스 +15%, 3턴. |
| 전기장 폭주 Lv.3 | 아군 전체 술식 위력 +35%, 마법 위력 +25%, 피해 보너스 +15%, 2턴. |
| 전력 | 최대 30스택. 해제되지 않는다. |
| 아크 라이트 | 스택마다 공격 +0.3%, 최대 60스택. |
| 진동 아크 | 스택마다 공격 +0.3%, 최대 240스택. 해제되지 않는다. |
| 균열점 | 폭력 봉합이 보너스 효과를 낼 때 소모한다. |
| 고온 용접 | 보유자가 공격받으면 코르부스가 아크 라이트를 1스택 얻는다. 정신 피해 공격이면 보유자의 정신 방어도 1% 낮추며(합계 최대 −50%), 코르부스가 1스택을 더 얻는다. 폭력 봉합은 고온 용접이 있는 적을 먼저 친다. 한 번에 한 적만 가질 수 있다. |
| 봉합 | 매 턴 종료 시 코르부스가 그때 술진 레벨의 효과로 폭력 봉합을 쓴다. 다시 얻으면 지속 시간이 늘어난다. |
| 서지 증폭 | 술진이 Lv.3에 이르면 열정 +3. 술진이 Lv.3인 동안 열정 최대치 +5, 제어 효과 면역. |
