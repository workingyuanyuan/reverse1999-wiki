에지오의 공격은 [암살]로 판정된다. 자신의 치명타 기술이 대상보다 100 높을 때마다 최종 피해가 오른다. 암살 발동, 표식이 붙은 적 반격, 적 처치로 동기화율을 채우며, 최종 술식은 선택한 적 하나를 여러 차례 타격한다. 주 무기 하나와 보조 무기 하나를 장착해 싸우며, 형상 2와 5가 그 효과를 강화한다.

## 주문

| 주문 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- |
| 어둠 속을 걷는다 (단일 공격) | 현실 피해 400% | 600% | 1000% |
| 빛을 섬긴다 (자신 카운터) | 적 하나에게 [포착된 시선], 에지오에게 [전투 경험] 1턴 | 2턴 | 3턴 |

- **어둠 속을 걷는다**는 모든 단계에서 암살로 판정된다.
- **빛을 섬긴다**는 공격 주문을 가장 많이 예약한 적을 표시한다.

## 최종 술식: 믿음의 낙인

에지오가 적 하나를 선택해 [신념의 화살] 또는 [신념의 칼날]로 3회 타격한 뒤 [죽음은 몰인정하지 않다]로 마무리한다. 적의 효과로 이 공격들의 대상을 바꿀 수 없다.

## 상태

| 상태 | 효과 |
| --- | --- |
| 암살 | 공격자의 치명타 기술이 대상보다 100 높을 때마다 그 공격의 최종 피해 +5%. |
| 포착된 시선 | 적이 에지오에게 주의를 돌려 팀을 노린 공격 일부가 에지오에게 먼저 향한다. |
| 전투 경험 | 아군이 공격받을 때마다 에지오가 [카운터 처치]로 반격한다. 다시 얻으면 지속 시간이 늘어나며 해제되지 않는다. |
| 카운터 처치 | 에지오 본인이 공격받았으면 현실 피해 500%에 치명타 피해 +50%, 다른 아군만 공격받았으면 500%. 암살로 판정된다. |
| 신념의 화살 | 단일 공격. 현실 피해 100%, 대상의 HP가 50% 미만이면 50% 추가. |
| 신념의 칼날 | 단일 공격. 현실 피해 100%, 대상의 HP가 50% 이상이면 50% 추가. |
| 죽음은 몰인정하지 않다 | 단일 공격. 현실 피해 700%. |
| 은신 암살 | 치명타 피해 +30%, 피해 감면 +40%. |
| 암살자 견습생 | 8스택에 도달하면 [마스터 어쌔신]으로 바뀐다. 다른 아군도 마스터 어쌔신을 얻으며, 암살 마도학자는 에지오 효과의 70%, 나머지는 50%를 받는다. |
| 마스터 어쌔신 | 암살 시 대상보다 높은 치명타 기술 100마다 최종 피해 +6% 추가. |
| 암살자 표식 | 다른 아군이 보유자에게 주문을 능동적으로 시전하면 에지오가 1스택을 소모해 1단계 어둠 속을 걷는다를 추격으로 시전한다. 이 추격은 표식을 추가하지 않는다. 최대 5스택. |
| 매의 인도 | 최종 술식 동안 소모된다. 2스택마다 신념의 화살 또는 신념의 칼날을 1회 추가한다. 최대 6스택. |
| 중독 | 매 턴 종료 시 부여자의 공격에 비례한 고정 피해를 준다. 중첩된다. |

신념의 화살, 신념의 칼날, 죽음은 몰인정하지 않다는 모두 암살로 판정되고 회피를 무시하며, 피해 분담이나 추가 피해를 발동하지 않는다.

## 무기

에지오는 주 무기 하나(베네치아 파르치온, 콘도티에로 전쟁망치, 선장의 검)와 보조 무기 하나(채널드 친퀘데아, 클리버, 술탄 나이프)를 장착한다. 형상 2는 각 무기를 강화한다.

| 무기 | 형상 2 |
| --- | --- |
| 베네치아 파르치온 | 대상에게 [암살자 표식] 2스택을 부여한다. |
| 콘도티에로 전쟁망치 | 다른 아군의 최종 술식 뒤 에지오가 [매의 인도] 2스택을 얻는다. 최종 술식 중 신념의 화살, 신념의 칼날, 죽음은 몰인정하지 않다마다 최종 피해 +2.5%. |
| 선장의 검 | 주문과 최종 술식 공격이 1단계 어둠 속을 걷는다 또는 죽음은 몰인정하지 않다 기본 현실 피해의 80%에 해당하는 고정 피해를 더한다. 대상의 중독 1스택마다 1.5%, 중독이 10스택 이상이면 2.5%가 더해진다. |
