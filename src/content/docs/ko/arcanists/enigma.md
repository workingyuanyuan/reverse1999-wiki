이니그마는 술진 [전기장 폭주]를 세우는 전력 서포터다. 매 턴 종료 시 [전력]을 술진에 주입하며, 주입할 때마다 [암호문]이 더해지고, 주입된 전력이 50이면 Lv.2, 120이면 Lv.3으로 오른다. 주문과 [순환 사슬]로 팀 전체의 [바스티온]을 유지하고, 최종 술식은 팀에게 치명타 피해와, 소모한 암호문에 따라 커지는 피해 보너스를 준다.

## 주문

| 주문 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- |
| 무한 디코딩 (단일 공격) | 현실 피해 200%, 아군 전체에게 암호문 3 | 300%, 암호문 4 | 500%, 암호문 5 |
| 사고의 교합 (자신 버프) | 공격의 280%만큼 바스티온 | 420% | 700% |

- 두 주문 모두 모든 단계에서 이니그마에게 전력 10스택을 준다.
- **사고의 교합**의 바스티온은 이미 가진 바스티온에 더해지며, 최대 공격의 1250%까지다. 바스티온을 가진 동안 매 턴 아군에게 걸리는 제어 효과를 처음 4번 막으며, 이 횟수는 팀 전체가 함께 쓴다.

## 최종 술식: 세계의 수수께끼와 정답

이니그마에게 [해독기]를 2턴 동안 주고, 아군 모두에게서 속성 감소, 상태 이상, 제어 효과를 모두 해제하며, 이니그마에게 [순환 사슬]을 5스택 준다. 폐쇄 순환 규칙을 한 번 쓰기에 충분한 양이다.

## 상태

| 상태 | 효과 |
| --- | --- |
| 전력 | 최대 30스택이며 해제되지 않는다. |
| 암호문 | 전력이 전기장 폭주에 주입될 때, 보유자의 암호문 스택만큼 술진이 전력을 더 얻고 암호문은 사라진다. 통찰 1이 상한을 올리기 전에는 최대 5스택이다. |
| 바스티온 | 아군 누구를 노린 피해든 흡수한다. 아군 1명, 2명, 3명, 4명 이상이 동시에 공격받으면 1당 피해 1, 1.2, 1.5, 1.8을 흡수한다. 바스티온이 다할 때까지 아군은 적의 피해로 HP를 잃지 않는다. 보호막과 함께 존재할 수 없다. |
| 전기장 폭주 | 술진. 턴 시작 시 주입된 전력에 따라 단계가 오른다. 50 이상이면 Lv.2, 120 이상이면 Lv.3이 된다. 술진이 끝나면 주입된 전력은 사라진다. |
| 전기장 폭주 Lv.1 | 아군 전체 피해 보너스 +15%, 3턴. |
| 전기장 폭주 Lv.2 | 아군 전체 마법 위력 +25%, 피해 보너스 +15%, 3턴. |
| 전기장 폭주 Lv.3 | 아군 전체 술식 위력 +35%, 마법 위력 +25%, 피해 보너스 +15%, 2턴. |
| 서지 증폭 | Lv.3에 이르면 이니그마가 열정을 1 얻는다. Lv.3 아래에서는 매 턴 시작 시 아군 전체가 암호문 3을 얻고, 아군마다 공격할 때 가진 전력 1스택당 마법 위력 +0.4%를 얻는다. 현실 피해 아군은 스택당 현실 피해 6%를 더 주고, 정신 피해 아군은 스택당 마법 위력 0.4%를 더 얻는다. |
| 순환 사슬 | 5스택이 되면 폐쇄 순환 규칙을 쓰고 5스택을 없앤다. 최대 9스택이다. |
| 폐쇄 순환 규칙 | 모든 적에게 현실 피해 200%. 아군 전체에게 암호문 5. 사고의 교합과 같은 조건으로 이니그마 공격의 280%만큼 바스티온. 이어서 이니그마가 열정 1과 전력 5를 얻는다. |
| 해독기 | 아군 전체 치명타 피해 +20%, 그리고 팀이 그때까지 없앤 암호문 1스택당 피해 보너스 +2%. 최대 30까지 세며, 적용되면 횟수가 초기화된다. |
