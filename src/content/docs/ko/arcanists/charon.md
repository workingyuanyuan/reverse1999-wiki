카론은 두 주문과 아군의 초과 열정, 전장을 떠나는 적·아군을 통해 [쇼크웨이브]를 모으며, 40스택을 얻을 때마다 [전율] 1스택을 얻는다. 최종 술식은 주문칸에 대기 중인 자신의 주문을 쇼크웨이브로 바꾸고 매 턴 종료 시 후회의 나날을 발동하는 음송에 들어가며, 통찰 1 패시브는 아군을 위해 [전기장 폭주]를 유지한다. 적에게 거는 [죽음의 공포]와 아군에게 주는 [진혼]은 카론이 가진 전율 스택에 따라 강해진다.

## 주문

| 주문 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- |
| 허무로부터 (전체 공격) | 정신 피해 200%, 쇼크웨이브 20 | 300%, 30 | 500%, 50 |
| 죽은 자의 간언 (아군 전체 버프) | 쇼크웨이브 20 | 30 | 50 |

모든 단계에서 허무로부터는 명중한 적에게 죽음의 공포를, 죽은 자의 간언은 아군 전체에게 진혼을 각각 2턴 동안 부여한다.

## 최종 술식: 양귀비가 만개할지라도

카론이 열정을 1 얻고, 주문칸에 있는 자신의 허무로부터와 죽은 자의 간언을 모두 제거해 카드 단계에 따라 1장당 쇼크웨이브 20, 30, 50스택을 얻는다. 이어서 [과거의 그림자] 상태에 들어간다. 과거의 그림자 상태에서 최종 술식을 다시 쓰면 늘어나는 쇼크웨이브 소모량이 초기화된다.

## 상태

| 상태 | 효과 |
| --- | --- |
| 과거의 그림자 | 매 턴 종료 시 후회의 나날을 발동한다. 첫 발동은 쇼크웨이브를 소모하지 않으며, 발동할 때마다 다음 소모량이 50스택씩 늘어난다. 쇼크웨이브가 부족하면 음송이 끝난다. |
| 후회의 나날 | 모든 적에게 정신 피해 150%를 주며, 술식 위력의 60%가 적용된다. 전율 1스택마다 정신 피해 50%와 술식 위력 적용 비율 10%가 더해진다. 카론은 보유한 쇼크웨이브 5스택마다 전력 1을 얻고 열정을 1 얻으며, 죽음의 공포와 진혼의 지속 시간이 1턴 늘어난다. |
| 쇼크웨이브 | 카론의 음송에서 소모하는 스택. |
| 전율 | 스택당 방어 무시율 +5%. 최대 10스택이며 스택마다 지속 시간을 따로 계산한다. |
| 죽음의 공포 | 치명타 방어 −20%, 카론의 전율 1스택마다 −5% 추가(최대 −20% 추가). 전율이 4스택 이상이면 받는 피해 +30%. 보유자가 공격받아 HP가 상태 부여 당시 최대 HP의 20%(카론 공격의 4000% 상한) 미만으로 떨어지면, 카론이 큰 [안정 고정 피해]를 준다. |
| 안정 고정 피해 | 능력치 보너스의 영향을 받지 않는 고정 피해. |
| 진혼 | 치명타율 +30%, 카론의 전율 1스택마다 +5% 추가(최대 +20% 추가). 전율이 4스택 이상이면 보유자의 상한을 넘은 치명타율 중 80%가 치명타 피해로 바뀐다. |
| 전기장 폭주 | 턴 시작 시 주입된 전력에 따라 레벨이 오른다. 50에 Lv.2, 120에 Lv.3이 된다. 전기장 폭주가 끝나면 주입된 전력은 사라진다. |
| 전기장 폭주 Lv.1 | 아군 전체 피해 보너스 +15%, 3턴. |
| 전기장 폭주 Lv.2 | 아군 전체 마법 위력 +25%, 피해 보너스 +15%, 3턴. |
| 전기장 폭주 Lv.3 | 아군 전체 술식 위력 +35%, 마법 위력 +25%, 피해 보너스 +15%, 2턴. |
| 서지 증폭 | 전기장 폭주 Lv.1이 바로 Lv.3으로 오르며, 이때 필요한 전력이 40 늘어난다. Lv.3에 도달하면 카론과 바로 앞의 아군이 [술식 간소화]를 얻고, Lv.3이 유지되는 동안 카론의 방어 무시율 +50%. |
| 술식 간소화 | 다음 최종 술식이 행동 횟수를 소모하지 않는다. 최종 술식을 직접 쓰면 사라진다. |
| 전력 | 최대 30스택이며 해제되지 않는다. |
