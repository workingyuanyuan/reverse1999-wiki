몰디르는 팀 전체가 소모한 열정만큼 [전투 태세]를 얻으며, 매 턴 시작 때 쌓인 스택이 10, 20, 30에 이르면 팀 버프가 열린다. 카운터 카드는 반격을 준비해 [주관]이 있으면 최종 술식으로, 없으면 무너진 과거로 반격한다. 최종 술식은 아군 전체에게 최종 술식의 치명타 피해를 올리는 [예의: 치명타 피해] 스택을 준다.

## 주문

| 주문 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- |
| 무너진 과거 (단일 공격) | 현실 피해 100% | 150% | 250% |
| 되찾은 내일 (자신 카운터) | 전투 태세 2스택 | 3스택 | 5스택 |

- **무너진 과거**는 공격 후 대상에게 [열정 추출] 1스택을 부여하고 몰디르에게 [연속 행동Ⅰ]을 1턴 동안 준다.
- **되찾은 내일**은 몰디르에게 주관이 있으면 [난관 돌파]를, 없으면 [섬광 공격]을 1턴 동안 준다.

## 최종 술식: 길을 찾은 귀로자

모든 적에게 현실 피해 400%를 주고 아군 전체에게 예의: 치명타 피해 6스택을 준다. 직접 시전하면 모든 적에게 현실 피해 300%를 추가로 준다. 반격으로 시전하면 전투 태세 4스택마다 아군 전체에게 예의: 치명타 피해 1스택을 더 주고, 몰디르가 [교리]를 2턴 동안 얻는다.

## 상태

| 상태 | 효과 |
| --- | --- |
| 전투 태세 | 턴 시작 시 스택 수에 따라 효과가 발동한다. 최대 50스택이며 해제되지 않는다. |
| 주관 | 열정 획득을 막는 [심란]에 면역이 된다. |
| 난관 돌파 | 아군이 공격받으면 몰디르가 최종 술식으로 반격하며, 발동하면 소모된다. |
| 섬광 공격 | 아군이 공격받으면 몰디르가 이 상태를 준 카드 단계의 무너진 과거로 반격하며, 발동하면 소모된다. |
| 열정 추출 | 보유자가 공격받으면 공격자가 열정 +1을 얻고 1스택이 사라진다. |
| 연속 행동Ⅰ | 행동 횟수 +1. |
| 전투 태세 구축 | 전투 태세 1스택당 최종 술식이 주는 피해 +2%. |
| 무장 정비 | 치명타율 +30%. 보유자가 최종 술식을 시전할 때 상한을 넘긴 치명타율이 치명타 피해로 바뀐다. |
| 예의: 치명타 피해 | 스택당 최종 술식의 치명타 피해 +3%, 최대 100스택. 발동하면 소모되며 해제되지 않는다. |
| 교리 | 술식 위력 +20%, 보유자는 주관을 얻을 수 없다. |

## 형상

| 형상 | 변화 |
| --- | --- |
| 1 | 무너진 과거가 단계에 따라 150%, 225%, 375%를 주고, 연속 행동Ⅰ이 2턴 지속된다. |
| 2 | 전투 태세 구축이 스택당 2.5%를 주고, 무장 정비가 치명타율 +40%를 준다. |
| 3 | 반격할 때마다 몰디르가 열정 +2를 얻는다. |
| 4 | 최종 술식이 500%를 주고 예의: 치명타 피해 8스택을 준다. |
| 5 | 최종 술식을 직접 시전할 때 추가로 600%를 주고, 교리가 술식 위력 +30%를 준다. |

## 광상

광상은 통찰 3 레벨 30에 열린다. 몰디르에게는 네 레벨짜리 발상이 하나 있으며, 주관을 팀 전체로 넓히고 카운터를 지속 반격으로 바꾼다.

| 발상 | 레벨 | 변화 |
| --- | --- | --- |
| 1 | 1 | 전투 태세가 10스택 이상일 때 몰디르만이 아니라 아군 전체가 주관을 얻는다. |
| 1 | 2 | 전투 태세 구축과 무장 정비가 기본값의 20%만큼 올라 스택당 2.4%와 치명타율 +36%가 된다(형상 2에서는 3%와 +48%). |
| 1 | 3 | 최종 술식이 기본 현실 피해의 100%에 해당하는 추가 현실 피해를 주며, 직접 시전과 반격 시전 모두 추가 피해와 추가 예의: 치명타 피해 스택을 받는다. 공격 전 몰디르에게 연속 행동Ⅰ이 있으면 무너진 과거가 기본 피해의 100%에 해당하는 추가 현실 피해를 주고 열정 추출 2스택을 부여한다. |
| 1 | 4 | 되찾은 내일이 섬광 공격을 2턴 동안 준다. 이후 섬광 공격은 턴당 1회 아군이 공격받은 뒤 무너진 과거로 반격하며, 몰디르에게 교리가 없는 매 턴 시작 시 난관 돌파를 1턴 동안 준다. |
