## 상태

- **구조 분석**: 턴 시작 시 여전히 해당 음송 상태인 경우 모든 적군의 피해 감면 -30%, 1턴간 지속. 해당 분석 중 \[암호키\] 1개당 추가 -4%(\[암호키\] 최대치는 10, 각각 분석 중인 \[암호키\]는 개별 계산)
- **예의: 술식 위력**: 최종 술식 위력 3% 증가(효과 중첩 가능, 최대 100스택 중첩, 해제 불가, 최종 술식 공격 시전 후 소멸)
- **전력**: 과학 기술의 산물, 정밀 기계 사용에 활용(중첩 가능, 최대 30스택 중첩, 해제 불가).
- **전기장 폭주**: 턴 시작 시 전기장 폭주는 주입한 \[전력\] 스택에 따라 레벨업: 주입한 \[전력\]이 50 이상일 시 술진은 \[전기장 폭주 Lv.2\]로 레벨업, 주입한 \[전력\]이 120 이상일 시 술진은 \[전기장 폭주 Lv.3\]으로 레벨업(전기장 폭주 소멸 시 주입한 \[전력\]도 함께 초기화)
- **빈도 분석**: 턴 시작 시 여전히 해당 음송 상태인 경우 모든 아군의 술식 위력 +30%, 1턴간 지속. 해당 분석 중 \[암호키\] 1개당 추가 +4%(\[암호키\] 최대치는 10, 각각 분석 중인 \[암호키\]는 개별 계산)
- **하이퍼 분석**: 턴 종료 시 여전히 해당 음송 상태인 경우 모든 적군에게 600%의 현실 피해를 주고, 해당 분석의 \[암호키\] 수량x100%의 추가 현실 피해를 줌. 이번 공격은 추가 행동으로 간주(\[암호키\] 최대치는 10, 각각 분석 중인 \[암호키\]는 개별 계산, 음송 시 행동 불가)
- **서지 증폭**: \[전기장 폭주 Lv.3\] 진입 후 열정 3포인트 즉시 획득, \[구조 분석\] \[빈도 분석\] \[하이퍼 분석\] 모두 \[암호키\] 5개 획득
