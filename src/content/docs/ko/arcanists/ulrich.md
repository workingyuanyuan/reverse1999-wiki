울리히는 [전력]을 모아 자신의 술진 [전기장 폭주]에 주입한다. 전력이 쌓이면 술진이 2레벨과 3레벨로 오르며 아군 전체의 피해와 술식 위력을 높인다. 두 주문은 각각 음송을 시작한다. 구조 분석은 적의 피해 감면을 낮추고 빈도 분석은 아군의 술식 위력을 올리며, 이미 음송 중일 때 다시 쓰면 술진에 전력을 주입한다. 최종 술식은 턴 종료 시 모든 적을 크게 공격하는 하이퍼 분석을 시작하고, [암호키] 스택이 세 분석을 모두 강화한다.

## 주문

| 주문 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- |
| 식별 모드 (자신 음송) | 3턴간 구조 분석 진입, 음송 중 사용하면 예의: 술식 위력 6스택 | 8스택 | 10스택 |
| 브라운 노이즈 (자신 음송) | 3턴간 빈도 분석 진입, 음송 중 사용하면 예의: 술식 위력 6스택 | 8스택 | 10스택 |

해당 분석이 이미 진행 중일 때 쓰면 두 주문 모두 모든 단계에서 최대 5의 전력을 전기장 폭주에 주입한다.

[예의: 술식 위력]: 스택당 술식 위력 +3%, 최대 100스택. 해제되지 않으며 최종 술식 공격 시 소모된다.

## 최종 술식: 무한 연산의 총합

울리히가 1턴간 [하이퍼 분석]에 들어가고 구조 분석과 빈도 분석의 지속 시간을 1턴 늘리며, 전력 30을 얻고 최대 30의 전력을 전기장 폭주에 주입한다.

## 상태

| 상태 | 효과 |
| --- | --- |
| 전력 | 최대 30스택. 해제되지 않는다. |
| 전기장 폭주 | 턴 시작 시 주입된 전력에 따라 레벨이 오르는 술진이다. 50 이상이면 2레벨, 120 이상이면 3레벨이 된다. 술진이 끝나면 주입된 전력은 초기화된다. |
| 전기장 폭주 Lv.1 | 아군 전체가 3턴간 피해 보너스 +15%를 얻는다. |
| 전기장 폭주 Lv.2 | 아군 전체가 3턴간 마법 위력 +25%, 피해 보너스 +15%를 얻는다. |
| 전기장 폭주 Lv.3 | 아군 전체가 2턴간 술식 위력 +35%, 마법 위력 +25%, 피해 보너스 +15%를 얻는다. |
| 구조 분석 | 음송: 턴 시작 시 울리히가 여전히 음송 중이면 모든 적이 1턴간 피해 감면 −30%를 받고, 구조 분석의 암호키 1개당 −4%가 더해진다. |
| 빈도 분석 | 음송: 턴 시작 시 울리히가 여전히 음송 중이면 아군 전체가 1턴간 술식 위력 +30%를 얻고, 빈도 분석의 암호키 1개당 +4%가 더해진다. |
| 하이퍼 분석 | 음송: 턴 종료 시 울리히가 여전히 음송 중이면 모든 적에게 현실 피해 600%를 주고, 하이퍼 분석의 암호키 1개당 100%를 더한다. 이 공격은 추가 행동으로 간주하며, 음송 중에는 행동할 수 없다. |
| 암호키 | 세 분석이 각각 따로 보유하는 카운터로, 각 분석당 최대 10개다. 해당 분석을 강화한다. |
| 피크 전위 | 광역 공격: 모든 적에게 현실 피해 150%를 주고, 구조 분석과 빈도 분석의 암호키 1개당 15%를 더한다. 술식 위력이 적용된다. |
| 서지 증폭 | 전기장 폭주가 3레벨에 도달하면 울리히가 열정 3을 얻고 각 분석이 암호키 5개를 얻는다. 술진이 3레벨인 동안 분석에 진입할 때마다 해당 분석이 즉시 암호키 5개를 얻으며, 하이퍼 분석의 암호키 1개당 현실 피해 +100%가 추가된다. |

## 광상

울리히의 광상은 중국 본토 서비스에만 출시되었다. 통찰 3 레벨 30에 열리며, 네 레벨짜리 발상이 하나 있다.

| 발상 | 레벨 | 변화 |
| --- | --- | --- |
| 1 | 1 | 술진이 3레벨에 도달할 때 서지 증폭이 열정을 4 준다. 구조 분석 중에 식별 모드를 쓰면 지속 시간이 3턴 늘어난다. 구조 분석의 암호키 상한이 5 늘어나고, 디버프가 턴 시작 대신 턴 종료 시 적용되며 1턴 더 지속된다. |
| 1 | 2 | 빈도 분석 중에 브라운 노이즈를 쓰면 지속 시간이 3턴 늘어난다. 빈도 분석의 암호키 상한이 5 늘어나고, 버프가 턴 시작 대신 턴 종료 시 적용되며 1턴 더 지속된다. |
| 1 | 3 | 피크 전위를 시전할 때 구조 분석이나 빈도 분석에 암호키가 10개 넘게 있으면 10개를 초과한 암호키를 소모한다. 소모한 암호키 1개당 전력 태그를 가진 현실 피해 아군이 2턴간 공격 시 현실 피해를 90% 더 준다. |
| 1 | 4 | 최종 술식의 하이퍼 분석이 2턴 더 지속된다. 음송 중에도 울리히가 행동할 수 있으며, 매 턴 종료 시 공격하기 전에 주문 구역에 있는 자신의 일반 주문을 가능한 한 모두 시전한다. |
