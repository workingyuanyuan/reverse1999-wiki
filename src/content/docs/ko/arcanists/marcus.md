## 주문

### 정독 수업

**1단계**: 단일 공격, 200%의 정신 피해를 줌.

**2단계**: 단일 공격, 330%의 정신 피해를 줌.

**3단계**: 단일 공격, 450%의 정신 피해를 줌. 이번 공격의 방어 무시율 30% 증가

### 불빛 사이

**1단계**: 광역 공격, 적 2명에게 130%의 정신 피해를 줌. 목표가 \[주석\] 상태인 경우, 30%의 추가 정신 피해를 줌

**2단계**: 광역 공격, 적 2명에게 200%의 정신 피해를 줌. 명중 시 대상이 \[쇠약\] 1스택 획득. 목표가 \[주석\] 상태인 경우, 40%의 추가 정신 피해를 줌

**3단계**: 광역 공격, 적 2명에게 300%의 정신 피해를 줌. 명중 시 대상이 \[쇠약\] 1스택 획득. 목표가 \[주석\] 상태인 경우, 75%의 추가 정신 피해를 줌

## 최종 술식: 더 멀리 닿는 시선

광역 공격, 모든 적군에게 250%의 정신 피해를 줌. 목표가 \[주석\] 상태인 경우, 200%의 추가 정신 피해를 줌. 자신은 \[사전준비·마커스\] 1스택 획득. 자신의 신기한 빛 +2

## 계승

**통찰 1 · 페이지 열람**: 신기한 빛 최대치 +1

턴 시작 시 적군이 \[주석\] 상태가 아닌 경우, 단일 적군에게 \[주석\] 부여(보스 목표 우선)

턴 시작 시 자신의 신기한 빛이 2 이상인 경우, 신기한 빛을 최대로 소모해 자신의 랜덤 주문 단계를 증가시킴. 1단계를 2단계로, 2단계를 3단계로 증가시킬 시 신기한 빛을 각각 2, 3 소모, 하급 주문 우선 증가

**통찰 2 · 페이지 열람Ⅱ**: 전투 진입 시 공격 5% 증가.

## 형상

**형상 1**: **페이지 열람**전투 시작 시 획득하는 신기한 빛 3으로 증가

**형상 2**: **페이지 열람**주문을 2단계에서 3단계로 높일 때 소모되는 신기한 빛 2로 감소

**형상 3**: **불빛 사이**주문 1/2/3단계 시 주는 정신 피해가 160/270/420%까지 증가

**형상 4**: **페이지 열람**턴 시작 시 획득하는 신기한 빛 2로 증가

**형상 5**: **정독 수업**주문 1/2/3단계 시 주는 정신 피해가 230/380/520%까지 증가

## 광상

**발상 1 · 레벨 1**: \[정독\] 추가 효과: 모든 아군이 2/3단계 주문 사용 후 마커스가 \[경험\] 1/2스택 획득. 턴 시작 시 \[경험\]을 1/2스택 소모해 1/2단계 예비 주문-정독 수업 1장 생성. \[경험\]을 1/2스택 소모해 1/2단계 예비 주문-불빛 사이 1장 생성

**발상 1 · 레벨 2**: **더 멀리 닿는 시선** 자신이 획득한 \[사전준비·마커스\]를 2단계 예비 주문-정독 수업 생성으로 변경.

마커스가 공격 시 \[경험\]을 2스택 소모해 주문 효과 강화:

**정독 수업** 추가로 기본 정신 피해 100%의 정신 피해를 줌, 3단계 방어 무시율 추가로 30% 증가

**불빛 사이** 추가로 기본 정신 피해 100%의 정신 피해를 줌. 목표가 \[주석\] 상태일 경우 추가로 90/120/225%의 정신 피해를 줌

**더 멀리 닿는 시선** 추가로 기본 정신 피해 100%의 정신 피해를 줌, 목표가 \[주석\] 상태일 경우 추가로 600%의 정신 피해를 줌

**발상 1 · 레벨 3**: \[주석\] 목표가 행동 시 더 이상 마커스의 신기한 빛 회복하지 않음, 마커스가 \[주석\] 상태인 목표 공격 시 초과한 치명타율이 치명타 피해로 전환, 신기한 빛 1 회복으로 변경

**발상 1 · 레벨 4**: \[경험\] 8스택 획득할 때마다 턴 종료 시 \[연속 행동Ⅰ\] 획득, 1턴간 지속

## 상태

- **주석**: 행동 시 사용자의 신기한 빛 +1, 턴마다 최대 3회 적용(해제 불가)
- **쇠약**: 공격 시 피해 보너스 -25%(적용 후 1스택 감소)
- **사전준비·마커스**: 다음 턴 시작 시 예비 주문-정독 수업 1단계 1장 생성. 마커스는 턴마다 사전준비를 통해 \[예비 주문\] 1장만 획득 가능
- **정독**: 2/3단계 주문 사용 시 자신의 열정 +1(해제 불가)
- **경험**: 예비 주문 또는 주문 강화에 사용
- **연속 행동Ⅰ**: 행동 횟수 +1
- **예비 주문**: 예비 주문 사용 시 동명의 주문으로 간주. 턴 종료 시 사용하지 않은 예비 주문은 전부 제거됨.
