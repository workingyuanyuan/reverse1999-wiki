마샤는 팀 전체에 중첩되는 보호막을 유지하고 모든 적을 불태운다. 통찰 1 계승으로 매 턴 [전장 응급치료]를 2스택 얻고, 아군이 공격받을 때마다 1스택을 써서 행동을 쓰지 않고 침묵의 무게를 쓴다. 공격과 소모한 전장 응급치료로 [고통 전이]가 쌓이고, 최종 술식이 이를 아군 전체의 [수행]으로 바꾼다. 마샤는 여광 마도학자에 속한다. 이들은 적이 연소나 빛무리를 받을 때마다 포인트를 쌓는다.

## 주문

| 주문 | 1단계 | 2단계 | 3단계 |
| --- | --- | --- | --- |
| 인내의 미덕 (단일 공격) | 현실 피해 200%, [연소] 3스택, 연소 8스택 이상이면 100% 추가 | 300%, 5스택, 150% 추가 | 500%, 8스택, 250% 추가 |
| 침묵의 무게 (광역 보호막) | 아군 전체에 마샤 공격의 150%만큼 보호막, 직접 쓰면 계수 + 치명타율 ×40% | 225%, ×60% | 375%, ×100% |

- **인내의 미덕**은 공격 뒤 마샤에게 고통 전이를 1스택 준다. 추가 피해는 대상에게 이미 연소가 8스택 이상 있을 때 적용된다.
- **침묵의 무게**의 보호막은 3턴 지속되며, 보유자에게 피해 감면 +30%를 준다. 이미 보호막이 있는 아군에게는 새 보호막이 더해져 마샤 공격의 650%까지 쌓이고, 지속 시간이 다시 3턴이 된다. 마샤가 직접 쓰면 전장 응급치료를 1 소모하고, 마샤의 치명타율에 표의 비율을 곱한 값을 보호막 계수에 더하며, 아군 전체에게서 속성 감소나 상태 이상 한 종류를 없앤다.

## 최종 술식: 폭력에 바치는 간언

마샤가 고통 전이를 1스택 얻고, 모든 적에게 현실 피해 750%를 주며 적마다 연소를 4스택 건다. 이어서 고통 전이를 최대 5스택 소모하고, 아군 전체가 같은 수만큼 수행을 3턴 동안 얻는다.

## 상태

| 상태 | 효과 |
| --- | --- |
| 연소 | 받는 치료 효과 −15%(중첩 불가). 턴 종료 시 보유자 공격의 4%를 기준으로 고정 피해를 준다. 최대 30스택이며 하나의 상태 이상으로 간주하고, 피해를 줄 때마다 스택의 절반이 사라진다. |
| 빛무리 | 받는 치료 효과 −25%(중첩 불가). 턴 종료 시 시전자 공격의 4%를 기준으로 고정 피해를 준다. 최대 30스택이며 하나의 상태 이상으로 간주하고, 피해를 줄 때마다 스택의 절반이 사라진다. |
| 고통 전이 | 스택마다 치명타율 +2.5%, 치명타 피해 +2.5%. 최대 20스택이며 해제되지 않는다. |
| 전장 응급치료 | 최대 2스택. 아군이 공격받으면 마샤가 1스택을 써서 1단계 침묵의 무게를 쓴다. |
| 수행 | 치명타율 +20%. 보유자가 피해를 줄 때 넘치는 치명타율의 50%가 치명타 피해로 바뀐다. 스택마다 마법 위력 +1%, 치명타 피해 +2.5%를 더하며 스택마다 지속 시간이 따로 흐른다. 해제되지 않는다. |
| 여광 | 적이 연소나 빛무리를 받을 때마다 쌓이는 포인트로, 남은 적이 적을수록 더 빨리 쌓인다. 신혈이나 간파의 눈과 함께 존재할 수 없다. |
| 낮의 기도 | 여광 아군이 1명, 2명, 3명 이상이면 여광이 3%, 5%, 8% 더 빨리 쌓인다. 3명이면 모든 적의 연소 스택 상한이 5 오르고, 매 턴 시작 때 여광 포인트 10마다 아군 전체가 그 턴 동안 치명타 피해 +1%를 얻는다. 포인트는 100까지 계산한다. |
| 사면 | 보유자에게 걸리는 첫 제어 효과를 막고 사라진다. 중첩되지 않는다. |
