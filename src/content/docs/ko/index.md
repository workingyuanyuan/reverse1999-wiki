## 모집

6성의 기본 확률은 1.5%다. 60회 연속으로 6성이 나오지 않으면 확률이 오르고, 70회 안에 6성이 확정된다. 횟수를 다음 모집으로 이월하는 것은 한정 캐릭터 모집뿐이며, 한정 모집, 콜라보 모집, 대부분의 이벤트 모집은 종료 시 초기화된다: [모집과 천장](/ko/systems/summoning/).

## 용어

| 용어 | 뜻 |
| --- | --- |
| 영감 | 마도학자의 유형. 천체, 암석, 야수, 나무, 영혼, 지능 여섯 가지다. |
| 통찰 | 세 단계(I, II, III)의 승급. 단계마다 레벨 상한이 오르고 계승 패시브가 하나 열린다. |
| 형상 | 다섯 번의 강화. 한 번에 같은 마도학자의 중복 1명을 쓴다. |
| 광상 | 일부 마도학자의 후속 강화. 통찰 3 레벨 30에 열리며, 네 레벨짜리 발상 두 개가 있다. |
| 열정 | 쌓이면 최종 술식을 쓸 수 있게 되는 포인트. |
