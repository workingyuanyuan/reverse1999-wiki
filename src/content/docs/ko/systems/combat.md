리버스: 1999의 전투는 턴 단위로 진행된다. 매 턴 팀은 주문 카드 한 패와 그 카드에 쓸 행동 횟수를 받고, 적은 자신의 행동 횟수로 행동한다. 피해는 공격자와 대상의 영감, 피해 유형, 그리고 아래 능력치에 따라 달라진다.

## 영감 상성

| 그룹 | 유리한 상대 |
| --- | --- |
| 야수 | 나무 |
| 나무 | 천체 |
| 천체 | 암석 |
| 암석 | 야수 |
| 영혼과 지능 | 서로 간의 별도 상성(영혼, 지능 상성) |

게임은 첫 번째 그룹을 자연 상성이라고 부른다. 두 그룹 모두 영감이 불리한 적을 공격하면 피해가 30% 늘어난다. 이 보너스는 피해 보너스와 별개다.

## 피해 유형

| 유형 | 줄이는 것 |
| --- | --- |
| 현실 피해 | 대상의 현실 방어 |
| 정신 피해 | 대상의 정신 방어 |
| 고정 피해 | 없음: 모든 방어와 피해 감면을 무시하는 고정 피해이며, 피해 보너스도 거의 받지 않는다 |

마도학자는 각자 현실 피해 또는 정신 피해를 준다. 고정 피해는 연소, 중독 같은 상태와 일부 스킬에서 나온다. 피해 유형은 제어에도 영향을 준다. 현실 피해 공격은 석화를, 정신 피해 공격은 빙결을 끝낸다([상태 효과](/ko/systems/statuses/) 참고).

## 주문과 행동 횟수

- 필드에 캐릭터 4명(지원 캐릭터 포함)이 있으면 패에 주문을 최대 7장까지 든다. 이 상한은 살아서 출전해 있는 캐릭터 수에 따라 달라진다.
- 주문을 시전하거나 패 안에서 옮기면 행동 1회를 쓴다. 카드를 같은 카드 위로 옮기면 단계가 오르며 최대 3단계다. 단계가 높을수록 강하며, 각 마도학자 페이지에 단계별로 나와 있다.
- 남은 아군이 적을수록 팀이 매 턴 받는 행동 횟수는 줄지만, 높은 단계의 주문을 얻기 쉬워진다. 마찬가지로 적을 처치하면 적이 하는 행동 횟수가 줄어든다.
- 이번 턴에 낸 카드는 턴이 진행되기 전에 행동 영역을 눌러 되돌릴 수 있다.

## 열정과 최종 술식

열정은 최종 술식이 소모하는 자원이다. 마도학자는 주문을 시전하거나 옮길 때, 그리고 일부 스킬로 열정을 얻는다.

- 출시된 마도학자 138명 중 131명은 최종 술식에 열정 5가 필요하다.
- 알렉시오스, 에지오 아디토레, 카산드라, 코펠리아, 에버에코, 쌍둥이, 헤도네는 대신 다른 자원을 채우며, 각 페이지에 나와 있다.
- 심란 상태의 마도학자는 열정을 얻지 못한다. 일부 적과 마도학자는 열정을 없앤다.

## 능력치

| 능력치 | 효과 |
| --- | --- |
| HP | 0이 되면 캐릭터가 전투에서 이탈한다 |
| 공격 | 공격이 주는 피해의 기반 |
| 현실 방어 | 받는 현실 피해를 줄인다 |
| 정신 방어 | 받는 정신 피해를 줄인다 |
| 치명타 기술 | 치명타율과 치명타 피해를 더한다 |
| 치명타율 | 치명타가 날 확률. 치료의 치명타 확률이기도 하다 |
| 치명타 저항률 | 치명타를 맞을 확률을 줄인다 |
| 치명타 피해 | 치명타의 피해. 치료가 치명타일 때의 치료량이기도 하며, 효과는 체감한다 |
| 치명타 방어 | 받는 치명타의 피해를 줄인다 |
| 피해 보너스 | 주는 피해를 올린다 |
| 피해 감면 | 받는 피해를 줄인다 |
| 방어 무시율 | 대상의 현실 방어와 정신 방어 일부를 무시한다 |
| 마법 위력 | 주문의 피해를 올린다 |
| 최종 술식 위력 | 최종 술식의 피해를 올린다 |
| 치료율 | 주는 치료량을 올린다 |
| 피해 회복 | 턴 시작 시 지난 턴에 받은 피해의 일부를 회복한다 |
| 흡혈률 | 준 피해의 일부를 공격자의 HP로 바꾼다 |
| 고정 피해 보너스 | 주는 고정 피해를 올린다 |
