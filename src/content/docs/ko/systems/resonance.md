## 공명의 작동 방식

공명은 생각으로 마도학자의 스탯을 올린다. 생각은 여러 모양의 조각이며 칸 위에 배치한다. 레벨이 오를 때마다 칸이 넓어지고, 생각이 늘거나 레벨이 오르며, 주요 생각도 오른다. 주요 생각은 마도학자가 속한 그룹 모양의 조각이다. 일부 마도학자에게는 같은 시스템의 이름이 감지, 변조의 이름이 감지 적응이다.

| 항목 | 내용 |
| --- | --- |
| 공명 변조 | 공명 레벨 10부터 |
| 주요 생각 최대 레벨 | 10(5성과 6성), 6(2성부터 4성) |
