## 효과

**증폭 1**: 기억자가 턴 시작 시마다 치료율 3% 증가, 해당 효과 최대 4스택 중첩.

**증폭 2**: 기억자가 턴 시작 시마다 치료율 3% 증가, 해당 효과 최대 5스택 중첩.

**증폭 3**: 기억자가 턴 시작 시마다 치료율 3% 증가, 해당 효과 최대 6스택 중첩.

**증폭 4**: 기억자가 턴 시작 시마다 치료율 3% 증가, 해당 효과 최대 7스택 중첩.

**증폭 5**: 기억자가 턴 시작 시마다 치료율 3% 증가, 해당 효과 최대 8스택 중첩.
