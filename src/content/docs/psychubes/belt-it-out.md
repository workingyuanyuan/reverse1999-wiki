## Effect

**Amplification 1**: When entering battle, for each character present with the \[Star\] afflatus, including the carrier, all allied \[Star\] afflatus characters gain DMG Dealt +2%, stacking up to 4 times.

**Amplification 2**: When entering battle, for each character present with the \[Star\] afflatus, including the carrier, all allied \[Star\] afflatus characters gain DMG Dealt +2.5%, stacking up to 4 times.

**Amplification 3**: When entering battle, for each character present with the \[Star\] afflatus, including the carrier, all allied \[Star\] afflatus characters gain DMG Dealt +3%, stacking up to 4 times.

**Amplification 4**: When entering battle, for each character present with the \[Star\] afflatus, including the carrier, all allied \[Star\] afflatus characters gain DMG Dealt +3.5%, stacking up to 4 times.

**Amplification 5**: When entering battle, for each character present with the \[Star\] afflatus, including the carrier, all allied \[Star\] afflatus characters gain DMG Dealt +4%, stacking up to 4 times.
