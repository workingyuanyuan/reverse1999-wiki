告死鸟在队伍下方维持一个术阵：涌动电场，并亲自布设它的第一级。她每次行动都获得电能，她的追击暴力缝合会把这些电能注入电场，使电场升到 Lv.2 与 Lv.3，每升一级对每名队友的增益就更强。她的咒语让她获得多层【电弧光】以提高攻击，并给一名敌人施加【断裂点】，暴力缝合会消耗断裂点触发加成效果。

## 咒语

| 咒语 | 1 阶 | 2 阶 | 3 阶 |
| --- | --- | --- | --- |
| 电弧绞线（单体攻击） | 200% 精神创伤；2 层电弧光 | 300%；4 层 | 500%；8 层 |
| 玫瑰色裂纹（自我吟诵） | 目标已有高温焊合时，2 层电弧光 | 4 层 | 8 层 |

- **电弧绞线**在每一阶都给命中的目标 1 层断裂点。
- **玫瑰色裂纹**让告死鸟进入【缝合】2 回合，并给敌方目标施加【高温焊合】。目标已经有高温焊合时，告死鸟另外获得表中的电弧光，目标获得 1 层断裂点。

## 至终的仪式：将飞逝缝入永恒

对一名敌人造成 700% 精神创伤，给予它 1 层断裂点，并触发一次暴力缝合。至终的仪式不计入队伍的咒语获取数量上限。

## 暴力缝合

单体攻击，视为额外行动。造成 400% 精神创伤，以 100% 的比例受仪式威力影响，并向涌动电场注入至多 20 层电能。其余效果取决于电场的等级；标示断裂点的加成需要目标持有 1 层断裂点，并会消耗它。

| 电场等级 | 额外伤害 | 消耗断裂点时 |
| --- | --- | --- |
| Lv.1 | 无 | 告死鸟获得 3 层电弧光 |
| Lv.2 | +200% 精神创伤 | 她每有一层电弧光，+5% 精神创伤 |
| Lv.3 | +600% 精神创伤 | 她每有一层电弧光或颤动电弧，+5% 精神创伤，仪式威力比例 +0.3% |

## 状态

| 状态 | 效果 |
| --- | --- |
| 涌动电场 | 术阵。回合开始时依注入的电能升级：50 以上升到 Lv.2，120 以上升到 Lv.3。电场结束时，其中的电能消失。 |
| 涌动电场 Lv.1 | 我方全体创伤加成 +15%，持续 3 回合。 |
| 涌动电场 Lv.2 | 我方全体术法威力 +25%、创伤加成 +15%，持续 3 回合。 |
| 涌动电场 Lv.3 | 我方全体仪式威力 +35%、术法威力 +25%、创伤加成 +15%，持续 2 回合。 |
| 电能 | 最多 30 层；无法被驱散。 |
| 电弧光 | 每层攻击 +0.3%，最多 60 层。 |
| 颤动电弧 | 每层攻击 +0.3%，最多 240 层；无法被驱散。 |
| 断裂点 | 由暴力缝合消耗，触发其加成效果。 |
| 高温焊合 | 持有者受到攻击时，告死鸟获得 1 层电弧光。精神创伤的攻击还会让它的精神防御降低 1%，累计最多 −50%，并让她再获得 1 层。暴力缝合优先攻击持有高温焊合的敌人；同一时间只有一名敌人持有。 |
| 缝合 | 每回合结束时，告死鸟以当下电场等级的效果施放暴力缝合。再次获得时延长持续时间。 |
| 电涌增幅 | 电场达到 Lv.3 时激情 +3；电场处于 Lv.3 期间，激情上限 +5，并免疫控制效果。 |
