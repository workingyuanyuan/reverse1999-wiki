卡戎通过两个咒语、全队溢出的激情与单位离场累积【休克波】，每获得 40 层便增加 1 层【颤栗】。他的至终的仪式会将咒语区里自己的咒语转化为更多休克波并进入吟诵，每回合结束时触发后悔日；洞悉一的传承则为全队维持【涌动电场】。敌人身上的【惧亡】与队友身上的【安魂】都会随他持有的颤栗层数而增强。

## 咒语

| 咒语 | 1 阶 | 2 阶 | 3 阶 |
| --- | --- | --- | --- |
| 来自虚无（攻击所有敌人） | 200% 精神创伤；20 层休克波 | 300%；30 层 | 500%；50 层 |
| 逝者谏言（全队增益） | 20 层休克波 | 30 层 | 50 层 |

来自虚无在每一阶都会对命中的敌人施加惧亡，逝者谏言在每一阶都会让我方全体获得安魂，皆持续 2 回合。

## 至终的仪式：纵使虞美人盛开

卡戎获得 1 点激情，移除咒语区里他所有的来自虚无与逝者谏言，每移除一张依阶次获得 20、30 或 50 层休克波，接着进入【往日阴影】。在往日阴影期间再次施放至终的仪式，会重置递增的休克波消耗。

## 状态

| 状态 | 效果 |
| --- | --- |
| 往日阴影 | 每回合结束时触发后悔日。首次触发不消耗休克波，之后每次触发使下一次的消耗增加 50 层。卡戎的休克波不足时，吟诵结束。 |
| 后悔日 | 对所有敌人造成 150% 精神创伤，以 60% 比例受仪式威力加成；每层颤栗额外增加 50% 精神创伤并使该比例提高 10%。卡戎每持有 5 层休克波获得 1 点电能，并获得 1 点激情，同时使惧亡与安魂的持续时间延长 1 回合。 |
| 休克波 | 卡戎吟诵时消耗的层数。 |
| 颤栗 | 每层穿透率 +5%，最多 10 层，各层持续时间独立计算。 |
| 惧亡 | 暴击防御 −20%，卡戎每持有 1 层颤栗再降低 5%（最多额外降低 20%）；达 4 层以上时，受到伤害 +30%。持有者受击且生命低于施加此状态时最大生命的 20%（此门槛上限为卡戎攻击的 4000%）时，卡戎造成大量【稳态本源创伤】。 |
| 稳态本源创伤 | 不受属性加成影响的本源创伤。 |
| 安魂 | 暴击率 +30%，卡戎每持有 1 层颤栗再提高 5%（最多额外提高 20%）；达 4 层以上时，持有者溢出上限的暴击率有 80% 转化为暴击创伤。 |
| 涌动电场 | 回合开始时依注入的电能升级：50 点升至 lv2，120 点升至 lv3。电场结束时，其中的电能会归零。 |
| 涌动电场lv1 | 我方全体创伤加成 +15%，持续 3 回合。 |
| 涌动电场lv2 | 我方全体术法威力 +25%、创伤加成 +15%，持续 3 回合。 |
| 涌动电场lv3 | 我方全体仪式威力 +35%、术法威力 +25%、创伤加成 +15%，持续 2 回合。 |
| 电涌增幅 | 涌动电场lv1 直接升至 lv3，需要 40 点电能。达到 lv3 时，卡戎与前方相邻队友获得【仪式简化】；lv3 存在期间，卡戎穿透率 +50%。 |
| 仪式简化 | 下一次至终的仪式不消耗行动点；主动施放至终的仪式后移除。 |
| 电能 | 最多 30 层；无法被驱散。 |
