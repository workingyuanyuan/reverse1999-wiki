回声谣没有普通咒语卡与一般的至终的仪式：她通过队伍以交感能量卡充能的【术具】施放咒语，并以同调值取代激情。她的术具会在两个咒语之间切换，一个是让每名队友获得【往日幽影】的攻击，另一个是需要【久违的光】的群体治疗；她还会给予我方全体【余念】，在生命降到 1 时承担剩余伤害。

## 咒语

| 咒语 | 效果 |
| --- | --- |
| 往日所寻求（群体攻击、损耗） | 对所有敌人造成 200% 现实创伤；我方全体获得 1 层【往日幽影】，持续 2 回合 |
| 明日所期盼（群体治疗） | 我方全体回复相当于回声谣攻击 180% 的生命；为每名队友驱散 2 种属性削弱、状态异常或控制效果 |

- **明日所期盼**每次施放会消耗 1 层久违的光。耗尽时，术具会切回往日所寻求。
- 【损耗】：术具施放这个咒语后，会在当回合停用。

## 交感能量卡

| 卡片 | 效果 |
| --- | --- |
| 光的生息 | 混沌交感能量 +1；回声谣获得 1 层久违的光。之后除非术具正选择于回忆中重逢，否则切换为明日所期盼。 |
| 光的生息Ⅱ | 与光的生息相同，混沌交感能量改为 +2 |
| 混沌交感能量Ⅱ | 混沌交感能量 +2 |

## 至终的仪式：于回忆中重逢

对所有敌人造成 500% 现实创伤，之后对所有敌人施加【空躯干】持续 3 回合，使我方全体获得 5 层往日幽影持续 2 回合，并使每名术具队友获得【恍然如故】持续 3 回合。之后若回声谣持有久违的光，术具会切换为明日所期盼；没有则切换为往日所寻求。

## 状态

| 状态 | 效果 |
| --- | --- |
| 术具 | 以交感能量充能；在行动序列末尾循环运转，消耗交感能量施放咒语。 |
| 往日幽影 | 创伤加成提高相当于回声谣攻击的 0.6%，每持有 1 层再额外获得创伤加成 +1%。最多叠加 15 层；再次获得时刷新持续时间。 |
| 久违的光 | 让回声谣的术具可以施放明日所期盼。 |
| 告慰之歌 | 持有者损失生命时，依损失生命的比例获得同等比例的余念最大值。 |
| 余念 | 生命降到 1 时，由余念承担剩余伤害。上限相当于回声谣攻击的 400%。 |
| 修复 | 累积 4 层时，能让持有者重新启动因损耗而停用的术具。最多叠加 4 层。 |
| 空躯干 | 现实防御、精神防御与暴击防御 −10%。 |
| 恍然如故 | 持有者每有 1 层往日幽影，暴击创伤 +2%。 |
