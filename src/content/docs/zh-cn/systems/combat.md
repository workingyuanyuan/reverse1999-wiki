## 回合

重返未来：1999 的战斗以回合进行。每回合队伍会拿到一手咒语牌与一定数量的行动次数（行动点），用来施放这些咒语；敌人则依自己的行动点行动。伤害取决于攻击者与目标的灵感、创伤类型，以及下列属性。

## 灵感克制

| 群组 | 克制 |
| --- | --- |
| 兽 | 木 |
| 木 | 星 |
| 星 | 岩 |
| 岩 | 兽 |
| 灵与智 | 两者之间另有一组关系（灵智克制） |

游戏把第一组称为自然克制。攻击灵感被克制的敌人时多造成 30% 伤害，两组皆然。这项加成与创伤加成分开计算。

## 创伤类型

| 类型 | 减免它的属性 |
| --- | --- |
| 现实创伤 | 目标的现实防御 |
| 精神创伤 | 目标的精神防御 |
| 本源创伤 | 无：固定伤害，无视所有防御与伤害减免，也几乎不受任何创伤加成影响 |

每位神秘学家造成现实创伤或精神创伤；本源创伤来自燃烧、中毒等状态与部分技能。创伤类型也关系到控制：现实创伤攻击会解除石化，精神创伤攻击会解除冰冻（见[状态效果](/zh-cn/systems/statuses/)）。

## 咒语与行动点

- 场上有 4 名角色（含支援）时，手牌最多 7 张咒语；上限取决于存活且上场的角色数。
- 施放咒语或移动手牌中的咒语都会消耗一次行动。把咒语移到相同的咒语上会提升它的阶次，最高 3 阶；阶次越高效果越强。
- 我方剩下的角色越少，每回合的行动次数越少，但越容易获得高阶咒语。同样地，击败敌人会减少敌人的行动次数。
- 本回合打出的咒语，在回合结算前点击行动区即可收回。

## 激情与至终的仪式

激情是施放至终的仪式所消耗的资源。神秘学家通过施放与移动咒语，以及部分技能获得激情。

- 138 名已上线神秘学家中，有 131 名施放至终的仪式需要 5 点激情。
- 阿利克西欧斯、艾吉奥·奥迪托雷、卡珊德拉、珐琅眼、回声谣、双生舞伶与赫多涅改为累积另一种资源。
- 心神不宁让神秘学家无法获得激情；部分敌人与神秘学家会移除激情。

## 属性

| 属性 | 作用 |
| --- | --- |
| 生命 | 降到 0 时角色退场 |
| 攻击 | 攻击所造成伤害的基础 |
| 现实防御 | 降低受到的现实创伤 |
| 精神防御 | 降低受到的精神创伤 |
| 暴击技巧 | 提高暴击率与暴击创伤 |
| 暴击率 | 打出暴击的概率；也是治疗暴击的概率 |
| 抗暴率 | 降低被暴击的概率 |
| 暴击创伤 | 暴击的伤害；也决定治疗暴击的治疗量，收益递减 |
| 暴击防御 | 降低受到的暴击伤害 |
| 创伤加成 | 提高造成的伤害 |
| 受创减免 | 降低受到的伤害 |
| 穿透率 | 无视目标部分现实防御与精神防御 |
| 术法威力 | 提高咒语的伤害 |
| 仪式威力 | 提高至终的仪式的伤害 |
| 治疗率 | 提高给予的治疗量 |
| 受创回复 | 回合开始时，回复上一回合所受伤害的一部分 |
| 吸血率 | 把造成的部分伤害转为攻击者的生命 |
| 本源创伤加成 | 提高造成的本源创伤 |
